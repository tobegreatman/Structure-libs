# stockframe · 个股研究复核框架

面向**中线 6–12 个月研究复核**（兼顾短线参考）的可追溯评分框架。
输出的是**研究分桶**（入池 / 观察 / 回避 / 人工复核）与**条件化结论**，不是买卖建议。

- 8 层分析：宏观 / 行业 / 公司 / 财务 / 估值 / 催化剂 / 交易面 / 风险
- 每个评分可拆解：维度 → 因子 → 指标 → 量规档位 → 原始字段（含来源与时点）
- 结论可证伪：维持条件 / 证伪条件各 ≥3 条，每条带可观测指标与阈值
- 时点纪律：字段级 `as_of` / `available_at`，越界即抛 `LookAheadError`；L4 传闻不得进评分
- 双估值：三情景 DCF + 相对估值分位带，只给区间，不给单点价位

## 快速开始

```bash
# 1) 图形界面（推荐）—— 浏览器打开 http://127.0.0.1:8770，顶栏直接输代码/名称
PYTHONPATH=src python -m stockframe.server --open

# 2) 命令行出报告
PYTHONPATH=src python -m stockframe.cli examples/sample_input.json \
    -o examples/sample_report.json --md examples/sample_report.md

# 3) 一键验收（30 项机检 + 单测）
PYTHONPATH=src python tools/acceptance.py

# 4) 校验 AI 写的一句话本质（字数/证伪阈值/违禁措辞/字段 ID）
python tools/check_logic_text.py --text-file draft.txt --json logic.json
```

判断层的四个提示词模板在 `prompts.txt`（政策取向、渗透空间、逻辑强度、一句话本质）；
其中一句话本质另有一版**网页版精简提示词**（不提字段 ID，给无本仓库上下文的通用 AI 用）。

政策取向 / 渗透空间 / 逻辑强度这三个字段的**档位判定**（1–5 整数的互斥判据、排除顺序、
回填 JSON 片段）在 `prompts_grading.txt`。它回答的是「同一份材料填 3 还是填 5」，
与取数提示词分开，是因为档位这一步才是打分差异的主要来源。

只想要一份能直接用的东西时，用 `prompt_three_grades.md`：**单文件、自包含**，
整篇复制给任意 AI（网页版也行），填好标的与分析时点即可（另两项可留空），拿到三个档位、
每档"为什么不是相邻档"的理由、改档触发条件，以及一句能被证伪的**一句话本质**（≤200 字）
和四段回填 JSON。它不引用仓库里的任何文件、模块或参数名，
`tests/test_grading_prompts.py` 会拦住有人往里加内部引用。

依赖：Python ≥3.10 标准库；`jsonschema` 可选（缺失时用内置结构校验）；`pypdf` 可选（只在解析年报 PDF 取客户集中度时用，缺了该项自动留空并告警，不影响主流程）。界面零前端依赖、无 CDN。

## 自动分析：输入代码或名称

顶栏搜索框输 `600519` 或 `贵州茅台` → 选候选 → 点「分析」，系统自动取数、装配、评分、出报告。

**自动填什么**（39 个字段里通常能填 35 个，剩下 4 个只能人工判断）：

| 层 | 自动内容 | 性质 |
|---|---|---|
| 行情 | 收盘价 / PE / PB / 十年分位 / 均线偏离 / 回撤 52 周 / 换手率 / 20 日量比 / 机构持仓变化 | 观测 + 计算 |
| 财务 | ROE-TTM / ROIC / 营收与净利增速 / 现金含量 / 负债率 / 商誉 / 应收+存货增速差 / TTM 口径 | 观测 + 计算 |
| 估值 | EPS-TTM、历史 P25–P75 分位带、同业 PE 中位数（东财同板块）、DCF 三情景机械外推假设 | 计算 + 显式假设 |
| 宏观 | M1 同比、制造业 PMI、10Y 国债收益率同比（中债日频曲线）：均按**保守发布日**判断可得性 | 观测值 |
| 行业 | 行业营收增速、量价趋势、生命周期阶段、龙头卡位（同业营收份额） | **代理** |
| 公司 | 护城河（毛利率溢价 + 稳定性 + ROIC>WACC 占比）、管理层记录（分红年数 + 质押比例反向）、质押比例 | 代理 + 观测 |
| 年报 | 最大客户收入占比（年报正文「公司前 5 大客户资料」第 1 名，巨潮 PDF 解析） | 观测（一手披露） |

**取数的四个兜底，都在报告里留痕**：

- **K 线**：东财行情主机对自动化访问限流（`RemoteDisconnected`），失败时自动切**新浪财经**日线；字段来源会写成"东财限流，改用新浪"。谁供的数据一看就知道。
- **换手率**：新浪不给换手率，用「当日成交量 ÷ 流通 A 股」现算。分母必须是流通口径——用总股本对有大量限售股的公司能低估一倍。
- **机构持仓变化**：没有"机构持仓"专门报表，改用**十大流通股东**明细里 `IS_HOLDORG=1` 的合计占流通比，季度对季度。口径只覆盖前十大，是方向性证据而非精确仓位，推导表里写明。
- **10Y 国债收益率**：东财数据中心不收录这条序列（此前只能留空），改从**中债**取 10 年期曲线日频数据。曲线是日终估值，按**次日可用**；一年前锚点取 365 天窗口内最近交易日，错位超 10 天就整项留空，不插值。

**有一项是从年报正文里读出来的：客户集中度**。东财 F10 经营分析只有经营范围/主营构成/经营评述，**确实没有客户表**（不是取数写法问题）；东财数据中心另外试过 7 个疑似报表名，全部返回「报表配置不存在」。但这张表是证监会年报格式准则的**强制披露项**，就印在年报正文里：「公司前 5 大客户资料」序号/客户名称/销售额/占年度销售总额比例。走巨潮三个公开接口（orgId → 年报检索 → PDF 原文）＋文本解析即可拿到**第 1 名**的占比，**全程不需要任何令牌**。

实测 11 家 A 股 2025 年报，披露形态并不统一：6 家标准表直接可得（宁德 13.73%、格力 5.91%、东财 1.57%、长盈通 24.59%），1 家用文字写「第一名和前五名分别占主营业务收入的 8.0% 和 35.8%」（中芯国际，分母不是销售总额），2 家只给前五名合计（茅台 10.10%、紫金 39.75%），2 家正文没有这张表（工商银行属行业不适用，北交所公司的年报格式准则不要求这一项）。**只有合计的那两家不填值**——合计是「前五家加起来」，把它当「最大一家」填进去会让风险档直接跳上去，上界写进缺口说明（「最大一家不超过 10.1%」）就够了。解析不出来时才回落到人工那一档（`kind=judgement`，与逻辑强度并列，不挂专属文案）。

客户名可能被匿名化成「客户1…客户5」——名称里的数字**不能**被当成噪声排掉，否则整张表会对不上、静默退化成「只有前五合计」（长盈通就栽过：真实 24.59% 被 54.59% 的合计盖住）。

解析器有两条硬纪律：**只认第 1 行**（最大客户必然是序号 1，格力那张表跨页断裂只剩 4 行，5.91% 照样拿得到），**五行之和必须等于合计**（实测 38.96=38.96、5.75≈5.74，容差 0.06pp，对不上就判「不一致」留空，宁可不要也不填错数）。

**年报口径 ≠ 季报口径（两把尺子）**：客户集中度一年只在年报里披露一次（现在自动读，所以这一项通常不用手填），所以"最新报告期"是季报时，它照样取**最近一期年报**（300750 在 2026-10-23 取值时是 2025 年报、2026-03-10 公告），滞后一年内属正常。这一点会影响两个地方：**时效性判断**按披露节奏算（年报字段 365 天，定期报告字段 92 天，只有行情是 1 天），否则年报公布三个月后就被判"超期"，年底年初看起来像"数据取不到"；**时点记录**上用年报期末作数据期、年报公告日作可获得时点（不是录入当日），否则一年前的数会被显示成今天刚拿到。报告里会同时给出这两个基准，数据质量备注也会声明这条是年报口径。

**同业锚不给点位**：自身 PE 11.6 倍、板块中位 31.8 倍，看着"折价 63%"，可代工、整机、材料混在同一板块，倍数差来自生意不同。所以只有当两者相差在 **0.5–2 倍**以内才折算价位，超出范围只报折溢价百分比、不给单点估值——与"只给区间不给点位"一致。

**"代理"是明确的三层区分**：`观测值`（数据源直接给的数字）→ `代理`（用公开报表按固定公式推断出档位，带公式与误差方向）→ `人工判断`（无法机读、必须人读）。代理不是研究结论，因此在字段、推导表、证据链三处都打 `proxy` 标记，界面用琥珀色标出；你一旦手工覆盖同一字段，标记就消失——它已经变成你给出的结论。

**它仍然读不了 4 项**：政策取向（要读政策文本）、渗透空间（无行业总量口径）、投资逻辑强度与一句话本质（这就是研究结论本身）。这 4 项进「缺口面板」，分组标注 `kind=judgement` 并可在面板直接填。客户集中度只在年报读不出来时（银行/保险、只有前五合计、扫描件）才补进这一档。

因此自动模式通常能拿到 **35/39 字段、判断层覆盖 81%**，落在 **`观察` 或 `入池`** 的正常区间（规则 `R6_SCORE_BAND`）；判断层证据不足时才会掉到 `人工复核 / R7_COVERAGE`。闸门刻意设在 60%：综合分只在有数据的维度上重归一化，若不设闸门，"只填了财务+行情"的标的也能拿 6–7 分，读者会误以为三层判断已经做过。

**字段账本永远对得平**：界面上的 `N/39` 加上缺口面板的字段数恒等于 39。待补分四类——`judgement`（须人读）、`data`（可机读但自动模式刻意未取）、`source`（本次取数失败/同业样本不足，见告警）、`other`。取数降级丢掉的字段会显式列出，不会凭空消失（机检 A19）。正常取数时只剩 4 项 `judgement`。

取数同样受时点纪律约束：指定 `analysis_date` 为历史某日时，尚未披露的报告不会被使用（会自动回退到上一期），而不是"用最新的"。宏观按惯例发布日保守后推（PMI 月末+2 天、M1 月末+15 天）；同业业绩报表没有公告日，按**法定披露截止日**判断（一季报 04-30 / 中报 08-31 / 三季报 10-31 / 年报次年 04-30）。

**取不到或算不出时，不装懂**。自动模式有三种明确拒绝，都是可读的 4xx，不会 500：

| 错误码 | 含义 | 界面表现 |
|---|---|---|
| `NOT_FOUND` | 检索不到该 A 股标的 | 提示换代码或名称 |
| `NO_PIT_DATA` | 分析时点之前没有任何已披露报告 | 提示改时点 |
| `DCF_INFEASIBLE` | 数据取到了，但机械外推的 DCF 跑不出正股权价值 | 见下 |

`DCF_INFEASIBLE` 多见于薄利重资产（如北交所部分标的）或净债务远高于盈利的公司：机械外推出的 FCFF 覆盖不了债务，此时任何"调参直到能出数"都是在编。所以系统**不调参**，而是把**已装配好的半成品输入一并返回**（响应带 `"partial": true`），界面自动载入 JSON 编辑器——你改掉 `assumptions.dcf` 里的营收增速、营业利润率、资本开支占比或净债务后点「分析」，走的就是手工管线。

```
GET  /api/search?q=600519     # 代码/名称检索
POST /api/fetch               # {query|secid, analysis_date, overrides} → 输入 JSON + 缺口报告
POST /api/analyze             # 与手工输入走同一条管线
```

| 视图 | 看什么 |
|---|---|
| 概览 | 分桶、综合分、置信度、八维雷达、贡献榜、贡献分层、维持/证伪条件、区间对照 |
| 评分卡 | 点开维度逐层下钻到指标：权重、档位、得分、rationale、证据四要素 |
| 估值 | DCF 三情景 + 敏感性热力图、相对法分位带、合成区间与安全边际 |
| 情景 / 风险 / 催化 / 跟踪 | 概率条、5×5 矩阵、事件时间轴、带阈值的跟踪项 |
| 数据质量 / 证据链 / 数据字典 | DQ 三要素、字段级溯源、39 字段可搜索 |
| 取数状态条 | 自动填充 N/39（+待补恒等于 39）、判断层覆盖与全维度覆盖、观测/代理条数、缺口分组（判断项可当场补）、推导过程（含代理公式与误差方向） |

- **输入面板**：直接编辑 JSON 运行；错误原样回显（例如把某字段 `available_at` 改到分析时点之后，会明确报 `LookAheadError` 与字段名）。
- **定性档位不盲选**：1–5 档下拉的每个选项都带锚定短语（如「4 档｜偏支持：有明确支持性政策在途」），选中后行内展开该档完整描述；档位仍严格按 `(档−1)×2.5` 换算成分数，前后端同一口径（机检 A26）。
- **估值前门**：银行/保险/证券/地产/亏损这类公司不出估值区间，估值页直接给理由而不是给数（`DCF_NOT_APPLICABLE`），分桶落"人工复核"（`R9`，机检 A28）。判据在 `datadict.COMPANY_PROFILES`，自动取数按申万二级行业名归类。
- **输入契约**：NaN/Inf、档位 4.7、档位 9、字段名拼错、价格 ≤0、文本字段塞数字——全部报错并点名字段，不再静默变成分数（机检 A27）。**DCF 假设层同一套契约**：`wacc=NaN`、`shares=0`、`wacc="0.08"`、缺 `dcf` 块都会指名字段报错；报告在返回前还会递归断言不含 NaN/Inf，因为 jsonschema 把 NaN 当合法 number，"校验通过"并不等于输出是合法 JSON（机检 A30）。
- **安全边际只有一个口径**：两法区间无重叠时不再输出"合成安全边际"（并集中点没有经济含义），改给 DCF 单法、相对法与分歧度三个数；终值占比 >70% 时 DCF 安全边际不进评分（机检 A30）。
- **分数归因**：评分卡顶部把综合分拆成「判断层 / 数据层 / 风险催化」三块贡献与权重占比，回答"这个分有多少来自人的档位选择"（`scorecard.score_attribution`）。
- **离线快照**：直接双击 `web/index.html` 也能浏览（只读内置样例），并提示如何启动本地引擎。
- 深链：`#scorecard`、`#risks` 等可直接定位视图；深浅色跟随系统。

## 判断层代理的边界（必读）

自动化的边界不是"能取多少数"，而是"推断到哪一步就必须交回给人"。本框架的分层是：

| 层 | 判定标准 | 例 |
|---|---|---|
| 观测 | 数据源直接给出的数字，无需推断 | M1 同比、PMI、质押比例 |
| 代理 | 用公开报表按**固定公式**推档位，公式与误差方向都写进报告 | 行业量价趋势、生命周期、护城河、管理层记录 |
| 人工 | 结论本身，或数据只在文本里且无法机读 | 投资逻辑强度、逻辑本质、政策取向、渗透空间（客户集中度只在年报读不出来时） |

代理项的已知失效面：护城河代理（毛利率溢价 + ROIC>WACC 年份）对资本密集代工低估壁垒，对银行/保险因毛利率不可比直接给空；管理层代理只看分红连续性与质押，读不出诚信瑕疵。所以代理值只用于"先有一份能看的报告"，采信前必须由研究人确认或改写（验收手册 R9 第 6 步）。

## 边界

- 不输出买卖、加减仓、点位或仓位建议；界面与报告同样受违禁措辞扫描约束。
- 单标的、单时点快照，不做组合与回测；DCF 输入为显式人工假设，报告中原样标注。
- 样例公司 `XX0000.DEMO` 为虚构标的，仅用于演示管线与格式；自动取数只覆盖 A 股。
- 自动取数为公开接口整理数据（标 L2），关键数字应回原始公告（L1）核对；接口可能限流或改版，失败时明确报错而不是给半份数据。
