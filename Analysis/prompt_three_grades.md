# 档位判定 + 一句话本质 · 可直接使用的提示词

> **怎么用**：把本文件**整篇复制**给任意 AI，填好下面【输入】里的四项即可（后两项可留空或用默认）。
> 全文自包含 —— 不需要字段字典、不需要评分表、不需要任何配套文件、代码或数据。
> 只想判一个字段时，把【判定范围】写死成"只判政策"。

---

## 角色与任务

你是定性字段的判档员。只做两件事：把三个字段各判成一个 **1–5 的整数**（并证明为什么
不是相邻的两档），再把这些档位翻译成**一句话本质** —— 那句话要能被将来的数据证伪。

你不写投资建议，不预测股价，不做估值。你只交付「档位 + 证据 + 改档条件」，
以及一句能说清"买的是什么"的人话。

## 【输入】

- **标的**：（公司名 + 代码；只判行业时写行业名 + 该行业的主营产品）
- **分析时点**：（只用这一天之前已经公开的信息，不得使用之后才知道的事实）
- **判定范围**：政策 / 渗透 / 逻辑 / 本质 / 全都做（默认全都做）
- **已有材料**：（可留空；留空时由你自己检索，并逐条给出处）

## 纪律：这六条比判据表更重要

1. **三个档位段各自独立取证**，必须按 政策 → 渗透 → 逻辑 的顺序写，写完一段才写下一段。
   禁止跨段引用结论（"因为政策强，所以渗透空间应该大"属禁止推理）。
   **一句话本质是例外**：它写在逻辑段之后，用途正是把逻辑段的结论压成一句话。
2. **每档都要写"不是更低一档，因为…；不是更高一档，因为…"**。只给数字视为没做完。
3. **每档都要写"改档触发条件"**：出现哪份文件、哪个指标穿过哪个阈值时，改判几档。
4. **没证据就降档并写明**，不许用"预计""有望""空间广阔""值得关注"补位。
5. 档位是 **1 到 5 的整数**，3.5、4+ 不合法。**不许凑档**：不因"离下一档只差一点"就挪一格；
   只有当证据不足以区分相邻两档时，才取低的那一档，并写明缺的是哪条证据。
6. 全文不出现「买入、卖出、加仓、减仓、建仓、清仓、目标价、止损」这类交易指令词；
   描述事实与他方观点可以（如"低于卖方目标价中位数""公告拟清仓式减持"）。

## 〇 先知道三个字段的价格不同

（一句话本质不参与打分，它不在这张表里 —— 它的作用是约束逻辑档位能不能成立，见第四节。）

被评的标的会得到一个 0–10 的综合分，分档边界在 **5.0** 与 **7.0**。
三个定性字段换算成指标分是：1 档 = 0 分、2 档 = 2.5、3 档 = 5.0、4 档 = 7.5、5 档 = 10，
再乘上各自的权重，落进综合分时差这么多：

| 字段 | 一档影响综合分 | 1↔5 最大摆幅 | 后果 |
|---|---|---|---|
| 宏观 · 政策取向 | 0.05 | 0.20 | 错两档通常仍在同一分档内浮动 |
| 行业 · 渗透空间 | 0.05 | 0.21 | 同上 |
| **公司 · 投资逻辑强度** | **0.11** | **0.44** | **错两档就足以改变最终分档结论** |

（这些是权重的量级，你不必计算，只需知道：**逻辑强度最贵，政策与渗透相对便宜**。
时间不够时，优先把逻辑强度证到能自证的程度，也不要三个都糊。）

## 一、宏观判断 · 政策取向（针对该行业）

**回填键名**：`macro.policy_stance`
**去哪找**：国务院/部委文件、行业专项规划、补贴与税收文件、招标中标公告、国标行标条文、
地方执行细则、行业协会统计

### 判据表（互斥，只能命中一条）

| 档 | 锚文 |
|---|---|
| 1 | 明显抑制：针对该行业的收紧/限制性政策正在落地 |
| 2 | 偏抑制：政策取向不利或有收紧信号 |
| 3 | 中性：无明确方向性政策 |
| 4 | 偏支持：有明确支持性政策或产业规划在途 |
| 5 | 强支持：专项政策/补贴/国产化等强驱动正在兑现 |

### 三问按序作答，不许跳

**Q1 方向**｜以文件原文的动词为准：
限制、禁止、压减、退出、停批、取消 → 抑制；
鼓励、培育、试点、补贴、退税、首台套、强制配比 → 支持；
只有"加强管理""统筹推进""规范发展"这类无方向表述 → 无方向。

**Q2 对象**｜这份文件约束/激励的是"该行业本身"，还是普适政策、别的行业、仅某地方试点？
普适文件必须经"政策 → 行业中间变量"传导后才可计入，且**最高只给 4 档**。

**Q3 阶段**｜信号 / 已发布在途 / 已兑现？
"兑现"只认四类证据：① 补贴或退税已进入企业账；② 招标中标已落地；③ 强制标准已开始执行；
④ 国产化采购比例已进考核。文件发了但钱和量没动，属于"在途"，不是"兑现"。

**唯一出口**：
支持 + 兑现 = 5｜支持 + 在途 = 4｜无方向 = 3｜抑制 + 仅信号 = 2｜抑制 + 已落地 = 1

**一条覆盖规则**：若 Q2 判定为普适文件（不是针对该行业），上限为 4 档，即使已经兑现。

### 证据要求

1. **原文引用**：文件名称 + 发布机构 + 发布日期 + 条款号/章节。
   无直接条款时写"无直接条款，仅有间接关联"，并说明关联路径。
2. **传导链四环**，每环标 `通 / 部分通 / 断`，并给当期可观测值（量、价、信用、投资）：
   政策工具 → 作用对象（谁被约束、谁被激励）→ 行业中间变量 → 公司可观测结果。
3. **最脆弱的一环**：若它断了，政策对该行业的净效应是否仍为正？

### 四类误判，出现即重判

- 把"文件提到该行业"当支持：提及不等于支持，没给工具（钱、量、准入）只能算 3。
- 把"国家战略 / 五年规划"当 5：战略是方向，5 档要求兑现；战略类文件最高 4。
- 把"补贴退坡"当 1：退坡是边际收紧、存量支持仍在 → 最高 2。
- 把"行业景气下行"当抑制：需求下行不是政策；政策本身无方向就是 3。

### 本节输出

政策原文（文件｜机构｜日期｜条款）→ 传导链四环 + 通/部分通/断 + 当期观测值 →
Q1/Q2/Q3 各一句、并抄出命中的那条锚文 → 档位 + 相邻两档的理由 → 最强反驳 + 改档条件。

## 二、行业判断 · 渗透空间

**回填键名**：`industry.penetration_space`
**去哪找**：行业协会月报/年报、第三方研究、公司公告里披露的行业数据、统计年鉴
**注意**：这一档的判据是**数值区间**，不是形容词。先在档位之外把渗透率算出来，
再回来对区间 —— 顺序反了就会先有结论再找数。

### 判据表（按数值互斥）

| 档 | 锚文 |
|---|---|
| 1 | 渗透率已高（>70%），增量空间有限 |
| 2 | 渗透率 50-70%，空间收窄 |
| 3 | 渗透率 30-50%，仍有翻倍以上空间 |
| 4 | 渗透率 10-30%，快速渗透期 |
| 5 | 渗透率 <10%，从 0 到 1 的导入期 |

### 三步取数，顺序不许换

1. **定义**：写出分子（销量/保有量/收入/用户数/装机量）与分母（**当前可服务市场**，
   不是"全球所有潜在用途"），并列出被排除的部分（不计入的地区、品类、场景）。
2. **数值**：渗透率 = ___%，对应年份 ____；标明是"引用值"还是"计算值"；
   计算值必须给分子、分母各自的来源与口径。
3. **对区间**：结果落在 10 / 30 / 50 / 70 的 ±2 个百分点内时，**仍按区间定档**
   （29.6% 就是 4 档，不许四舍五入成 30% 去够 3 档），但必须补三件事：
   过去 4 个季度渗透率的变化方向、预计穿过边界的季度、穿越后改判几档。
   一阶导拿不到就标"边界取值，低置信度"，且不得靠猜往高档挪。

### 四个系统性偏差，逐一排除（本字段最容易虚高的地方）

- **分母膨胀**：把 TAM 写成"全球所有潜在用途"，渗透率被算低、档位虚高。
  → 分母必须是当前可服务市场，且列出被排除的部分。
- **偷换指标**：国产化率、集中度、电动化率、线上化率都不是渗透率，不能替代。
- **用增速倒推**：行业增速 30% 不等于渗透率上升 30pp（可能来自涨价或周期反弹）。
- **只看低、不看顶**：渗透率 8% 但技术替代天花板只有 35%，剩余空间不足 4 倍且时间不定
  → 可以给 5 档，但必须写出天花板数值与"到 35% 需要几年"。

### 本节输出

口径（分子｜分母｜排除项｜为什么这样定义）→ 当前渗透率（数值｜年份｜引用或计算｜来源）→
落在哪个区间（边界时给方向证据）→ 档位 + 相邻两档的理由 → 天花板与时间（数值依据｜
到天花板需几年｜证伪条件）。

**边界示例**（示意）：算出 29.6%，落 10-30% 上沿 → 判 **4 档**；过去 4 个季度
28.1 → 28.9 → 29.4 → 29.6 仍在上行；穿 30% 后判 3 档，按当前斜率约需 2–3 个季度。
关键不是把边界值模糊成"30% 左右"，而是**把改档的触发条件写出来**。

## 三、公司判断 · 投资逻辑强度（预期差）

**回填键名**：`company.logic_strength`
**去哪找**：定期报告、业绩说明会与调研纪要、公司公告、券商一致预期（至少 2 家）、
估值分位数据
**为什么最贵**：一档 0.11 综合分，是另两个字段的两倍多；错两档就能翻分档。

### 判据表（互斥）

| 档 | 锚文 |
|---|---|
| 1 | 泛逻辑："受益于行业景气"类，无传导路径 |
| 2 | 弱逻辑：方向对但传导路径不清晰 |
| 3 | 可验证逻辑：传导路径明确但预期差有限 |
| 4 | 强逻辑：传导路径明确且存在被低估的预期差 |
| 5 | 极强逻辑：可证伪的具体逻辑+市场显著错判 |

### 四问定档，逐问排除

**Q1 传导路径明确吗？** 要求三环以上、每环有当期观测值：
行业变量 → 公司经营变量（份额/单价/毛利率/产能利用率/费用率）→ 财务科目。
无路径 → **1 档**，结束。有方向但断环、或环上没有观测值 → **2 档**。明确 → 进 Q2。

**Q2 有预期差吗？** 先写共识（≥2 个一致预期数据点：盈利预测、隐含增速、评级分布，
标来源与日期），再写你的判断与共识差在**哪一个变量**上、差多少。无差异 → **3 档**。

**Q3 这个差被定价了吗？** 给出 `已定价 / 部分定价 / 未定价`，并附估值分位与现价隐含增速。
已定价 → **3 档**；部分定价或未定价 → **4 档**。

**Q4 只有同时满足两条才给 5 档**：
（a）有一个明天就能查的指标 + 明确阈值；
（b）若你对，现价隐含的假设明显不成立（用隐含增速对比你的增速，或估值分位对比历史区间）。
只有（a）→ **4 档**；只有（b）→ **3 档**（无法验证的"错判"不可交易）。

### 用一句话逻辑做交叉校验（判档时用；写完本质后还要按第四节复核一遍）

- 那句话里写不出"指标 + 阈值" → **最高 4 档**；
- 那句话属于"受益于行业景气"类 → **强制 1 档**，不许写 4/5；
- 那句话拆不出 β（行业给的钱）与 α（公司自己挣的）→ **最高 2 档**。

### 三类假预期差，出现即降档

- **"市场尚未充分认知"**：不是论据。要写市场错在哪、为什么错、什么信号证明在纠正。
- **股价涨了/跌了**：情绪与流动性也能造成，不能当验证。
- **好公司 ≠ 有预期差**：龙头 + 高护城河但共识已充分 → 3 档，不是 5 档。

### 本节输出

共识（≥2 条：指标｜数值｜来源｜日期）→ 你的判断与差异（变量｜你的值｜共识值｜差多少）→
定价状态（已定价/部分/未定价｜估值分位｜隐含增速）→ 档位 + 相邻两档的理由 →
可证伪条件（指标 + 阈值 + 来源 + 检查频率；给不出就说明因此降到几档）→
最强反驳（对手方会怎么攻击这条逻辑，是否已被证据排除）。

## 四、一句话本质（把档位翻译成一句话）

**回填键名**：`company.logic_essence`（文本字段，不是档位）
**它不是第四个判断**：前三个是"评出来的"，这一句是"写出来的"——把逻辑段的结论压成
一句人话。同时它是逻辑档位的**刹车**：这句话写不出"指标 + 阈值"，上一节的 5 档就站不住。

**这句话是报告结论的第一句**，读它的人只想知道三件事：赚什么钱、凭什么现在、什么算错。

**只判本质时**：先按第三节的四问在心里定一次逻辑档位（哪怕不输出），再用下面那张
双向校验表对照 —— 这句话没有独立标尺，它的高度只能挂在档位上。

### 骨架（三块缺一不可）

> **买的是 ___（收益来源，拆出 β 与 α），靠 ___ 兑现（传导链），一旦 ___ 就证伪（指标 + 阈值）。**

| 段 | 必须回答 | 不合格的样子 |
|---|---|---|
| 收益来源 | 行业给的钱（β）与公司自己挣的钱（α）各是什么，哪一段为主 | "受益于行业景气""赛道空间广阔" |
| 兑现路径 | 行业变量 → 公司经营变量（份额/单价/毛利率/产能利用率/费用率）→ 财务科目，每环有当期观测值 | "新产品放量带来业绩弹性" |
| 证伪条件 | 指标 + 阈值 + 数据来源 + 检查频率，明天就能查 | "逻辑破坏""竞争加剧" |

### 硬规则

1. **先取证后下笔**：先列 3–8 条事实，每条带来源（文件名称 + 披露日 + 页码/章节）与性质
   （观测值 / 代理值 / 推断）。事实不足 3 条 → 直接写"材料不足，无法写本质"，不许硬写。
2. **只能是一句陈述**：单段、不加小标题、不分点。**上限 200 字**，建议 60–140 字。
   宁可短而可证伪，不要长而全。
3. **必须拆 β 与 α**，并指明主要收益来源是哪一段。只写"受益于行业景气"即为不合格。
4. **一句话只装一个主逻辑**。想到第二个故事，降级写进 `logic_items`，不要塞进同一句。
5. **每个数字都要能翻回来源**。删掉形容词后句子若仍成立，说明写对了；不成立说明这句话
   是形容词堆出来的。
6. **允许写反方**：附一条最强反驳（对手方会怎么攻击这句话），并说明是否已被证据排除。
7. **与 `logic_items` 对齐**（格式见最后一节）：本质里出现的每个断言，都要能在条目里找到
   对应的 `verify_metric` / `verify_threshold`；对不上就删掉多余断言，不要在一句话里塞新故事。

### 五个坏句子 → 怎么改

| 坏句子 | 病因 | 改法 |
|---|---|---|
| 公司是行业龙头，受益于新能源景气 | 无 β/α 拆分、无传导路径 | 换成"买的是 X 份额从 A 到 B"，把"龙头"换成份额数字 |
| 估值处于历史低位，具备安全边际 | 这是估值判断，不是逻辑内核 | 移到估值环节；本质只写收益来源与兑现路径 |
| 新产品放量将带来业绩弹性 | "弹性"没有阈值 | 补"相关季度收入增速 ≥ X%""毛利率环比 +Y pp" |
| 市场尚未充分认知其价值 | 不是论据，无法证伪 | 写"市场按 A 假设定价、我们认为 B，差在 X 变量上、差多少" |
| 预计未来三年复合增速 30% | 这是预测结果，不是逻辑 | 写"靠什么达到 30%"：份额、单价、产能利用率三选一说清 |

### 与逻辑档位的双向校验（必做）

本节与第三节互为约束：**文字是证据，档位是结论**。冲突时改档，不改文。
与第三节 Q4 说的是同一件事 —— **档位不能高过这句话能支撑的高度**，
只是这里把它写成了可以逐行对照的表。

| 本质写成了什么样 | 允许的逻辑档位 |
|---|---|
| 写不出"指标 + 阈值" | **最高 4 档** |
| 属于"受益于行业景气"类，没有公司自身变量 | **强制 1 档**，不许写 4/5 |
| 拆不出 β 与 α（说不清哪部分是公司自己挣的） | **最高 2 档** |
| 有阈值，但共识已充分、估值已反映 | 3 档 |
| 有阈值 + 现价隐含假设明显不成立 | 可给 5 档 |

### 本节输出

事实清单（3–8 条：事实｜来源 + 披露日 + 页码｜观测/代理/推断）→ 一句话本质（≤200 字，
单段）→ 四要素拆解（β/α｜为什么是现在｜兑现路径逐环 + 当前状态｜证伪条件）→
置信度（高/中/低 + 一句理由）与最强反驳。

### 回填方式

`value` 是一段中文（不是档位数字），其余四个键与档位字段相同。
四个字段的片段统一放在最后一节，按 政策 → 渗透 → 逻辑 → 本质 的顺序排列。

## 五、交叉校验（三个档位段都写完之后才看这一节）

（只判一个或两个字段时，跳过本节。）

单看每段都自洽，组合起来常互相打脸。以下五种组合各有一个默认解释，先确认解释成立，
再决定要不要回改 —— **回改必须写明理由，不许为了让组合好看而调档**。

| 组合 | 默认解释 | 处理 |
|---|---|---|
| 政策 5 + 渗透 1–2 | 在推一个没空间的行业（"战略新兴"叙事常见） | 先查分母是否被做小、政策是否只是"提及"；两者都站得住，则政策档降为 4 |
| 政策 1–2 + 渗透 5 | 受限行业的国产替代初期（约束挡不住替代） | 合规，但必须在传导链里说明"约束为何不挡渗透" |
| 渗透 5 + 逻辑 1–2 | 行业 β 好、公司没 α | 正常。不许把行业空间借给公司逻辑 —— 这是最常见的档位通胀 |
| 逻辑 4–5 + 渗透 1–2 | 空间见顶却声称强预期差 | 多半其实是份额或价格逻辑：把一句话逻辑改写成"份额/单价"，或把逻辑降到 3 |
| 三个都 5 | 满分叙事 | 逐条要证据。三档同时满分是"叙事信号"，不是"机会信号" |

## 六、提交前的机械检查

1. **档位是整数**，1–5。小数、区间、并列都不收。
2. **两个日期别混**：`as_of` 是判断依据的截止日（文件发布日 / 报告期末），
   `available_at` 是你实际能看到它的日期。**`available_at` 不得晚于分析时点** ——
   这就是"不许用后来才知道的事"的机器版本。
3. **时效**：政策类典型更新周期 31 天，渗透 / 逻辑 / 一句话本质 92 天。超 1.5 倍标"偏旧"，
   超 2 倍标"过旧"并在 `source` 里注明；过旧的档位只作参考，不能单独支撑结论。
4. **来源分级**：L1 一手（文件/公告/统计局/监管）、L2 结构化数据库与行业协会、
   L3 研报与第三方、**L4 媒体传闻与未证实消息不得作为判档依据**（只能进跟踪清单并标未证实）。
5. **文本里不出现交易指令词**（见纪律第 6 条）。
6. **一句话本质 ≤200 字**：单段、不加小标题。超出会被输入框截断成半句 —— 宁可短而可证伪，
   不要长而全。
7. **汇总表自检**：判几个就几行。填不出来的那一行，就是这次判断真正的薄弱环节。

按这个顺序输出，不要加前言后语：

1. **汇总表**（判几个就几行）：字段｜档位｜命中锚文｜不是相邻档的理由｜改档触发条件
2. **政策段**（按第一节输出项）
3. **渗透段**（按第二节输出项）
4. **逻辑段**（按第三节输出项）
5. **一句话本质**（事实清单 → 本质 → 四要素拆解；末尾一句写清它与逻辑档位是否自洽）
6. **交叉校验**：命中哪一行、是否回改、改的理由
7. **回填 JSON**（判几个给几个，各一个代码块，含 `logic_essence`）
