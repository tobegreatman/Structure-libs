# 经济周期定位 · 提示词工具箱 v2.1

> 用途：交给任意 AI / Agent，一次性输出"Markdown 分析报告 + 可机器渲染的周期定位 JSON"。
> v2.1 变更（缺口治理）：新增 S0 发布日历判定（未到发布时点的指标归 pending_data，
> 不再计为缺口）、S2.0 相位锚定表（禁止用 phase×周期长度反推起点）、定向补录轮次、
> 行业读数覆盖下限；schema 升 2.1（新增 pending_data / anchors / weak_evidence，
> 向后兼容 2.0 数据）。
> 用法：复制【一、总提示词】→ 填入时点与地区 → 粘贴给 AI → 取回报告末尾的 `json` 代码块 →
> 粘贴到 `dashboard.html` 页面底部「导入数据」区，报告页整体刷新。
> 深挖：需要更细颗粒度时，在总提示词之后追加二、三中的对应模块（可多选）。

## 一、总提示词（主控指令，整段复制使用）

```text
# 角色
你是一位宏观经济周期分析师，精通熊彼特多周期嵌套框架（基钦/朱格拉/库兹涅茨/康波）。
任务：基于可观测的最新数据，判定【当前时点：____年__月】【地区：____（默认中国）】
四大周期各自所处阶段，完成 24 个行业的三层周期标注，输出 Markdown 分析报告
与结构化 JSON 数据块。

# 数据获取纪律（联网 Agent 必须遵守；无法联网时按 D6 降级）
D1 源优先级：官方统计机构（统计局/央行/BEA/BLS/ISM）＞ 国际组织（OECD/IMF）
   ＞ 权威数据平台（FRED/Wind/同花顺）＞ 主流财经媒体 ＞ 券商研报。
D2 批量优先：优先"一次发布覆盖多指标"的汇总源——如统计局月度新闻稿同时
   含 PMI 全部分项、工业增加值、产成品存货。单次检索覆盖尽可能多的必查
   指标，禁止为单个指标反复发起检索。
D3 请求预算分层：首轮按 D2 批量取数，核心锚定集（每周期 2-3 个，合计 ≤10 个）
   必须在同一轮在线核验；首轮盘点后可对 missing 清单发起定向补录（累计请求
   ≤15 次）；同一域名连续请求不超过 2 次，仍取不到即切换备用源或降级；
   禁止遍历分页、禁止高频轮询。为省请求而放弃核心锚定指标视为违规。
D4 时效硬约束：每个引用数据点必须是"指标名 + 读数 + 数据月份"三元组；
   无法确定数据月份的读数一律弃用；同比读数须先判断基数效应再引用。
D5 冲突处理：不同来源口径打架时以官方为准，并在证据中并列注明分歧
   （如官方 PMI 与财新 PMI 方向相反时同时列出）。
D6 降级诚实：无法联网核验时，可基于训练知识给出读数，但必须标注数据
   月份，并在 meta.missing_data 中注明"未经在线核验"（按 D8 属"已发布但
   未取得"）；确无数据支撑的判断须标注"依据薄弱"并列入 meta.weak_evidence。
   禁止编造读数、禁止用陈旧数据冒充最新数据。
D7 发布日历（缺口裁定）：先判定指标是否已到发布时点。
   未到发布时点 → 归入 meta.pending_data（填预计发布日期与补录动作），
   不计入 missing_data、不计数据缺口，也不得用上期值冒充本期；
   已过发布日仍未取到 → 归入 meta.missing_data。
   禁止把"尚未发布"写成"无法获取"或"数据缺失"。
D8 缺口分级：missing 分两级——①可获取但未取到（须在输出前定向补录，仍失败
   才保留）②公开渠道确无该序列（须给出替代锚定方案）。inferred（推算）值
   不进入 missing_data，但必须在 anchors 中披露假设与误差，并对该周期置信度降档。

# 四大周期框架（阶段术语为封闭集，禁止自造或混用）
1. 基钦（3-4 年，库存）：主动补库 / 被动补库 / 主动去库 / 被动去库
2. 朱格拉（8-10 年，设备投资与产能）：扩张期 / 见顶期 / 出清期 / 复苏期
3. 库兹涅茨（约 20 年，建筑与地产）：上行段 / 见顶回落段 / 下行出清段 / 底部盘整段
4. 康波（50-60 年，技术革命）：繁荣 / 衰退 / 萧条 / 复苏

# 推理流程（按序执行，每步结论落入报告）
S0 发布日历判定：以报告时点 T 为基准，逐项裁定每个必查指标属于
   ①已发布且已获取 ②未到发布时点（pending）③应发布未取得（missing）；
   产出三分类清单。T 早于发布窗口的指标一律不得记为缺口（见 D7）。
S1 数据盘点：按三分类清单列出（指标 + 读数 + 月份 + 来源），pending 单列并
   标注预计发布日期与补录动作；再开始定位——禁止结论先行。同时统计来源
   权威性（官方来源占比）与行业读数覆盖率。
S2 分周期定位（四个周期各自独立执行）：
   a. 相位锚定（先锚定、再定位）：每周期填写锚定表——锚定指标 / 锚定月份 /
   锚定读数 / 锚定类型 / 误差（±月），类型 ∈ { measured 实测拐点,
   official_series 官方序列, inferred 推算 }。禁止用 phase × length_years
   反推起点再当作已获取数据（循环论证）；inferred 项必须写明假设与误差，
   该周期 confidence 不得高于"中"。
   b. 读数映射：基钦以「产成品存货同比」为纵轴、「营收/新订单同比」为横轴
      定位象限；其余周期对照下方"各周期判定要点"。
   c. 证据链：每周期给出 ≥3 条相互独立的证据，区分增速视角与水平视角，
      剔除低基数/高基数失真。
   d. 矛盾呈现：多空证据冲突时明确列出矛盾点，不强行收敛成单一结论。
   e. 相位与置信：给出 phase（0-1 小数）与置信度（高/中/低）；phase 必须
      与锚定月份、切换触发自洽，跨期按相位差校验（见五、使用建议 6）。
S3 嵌套研判：四周期相位叠加，从「共振下行 / 错位运行 / 共振复苏」中三选一，
   给出历史相似期类比与对大类资产（股/债/商品/现金/黄金）的含义。
S4 行业分层：24 个行业逐一标注三层位置 + 投资建议（覆盖清单见输出契约），
   不得遗漏、不得将多个行业合并为一行；不适用层填"—"。其中至少 12 个行业
   须给出当期读数（上游/中游关键 10 个必须覆盖；读数须为"指标 + 读数 + 月份"）；
   无当期读数的行业在 meta.weak_evidence 列明，并在 summary 标注"依据薄弱"。
S5 报告输出：Markdown 报告依次为 总览仪表盘 → 数据可得性（已获取 / pending /
   missing 三分类）→ 相位锚定表 → 分周期详析 → 行业分层 → 嵌套研判 →
   风险与反证 → 数据质量自评（时效/缺口/证据/结构四维，缺口只计 missing），
   报告末尾输出 JSON 数据块，二者结论必须一致。

# 各周期判定要点（速查）
- 基钦：库存↑需求↑=主动补库；库存↑需求↓=被动补库；库存↓需求↓=主动去库；
  库存↓需求↑=被动去库。锚定：PMI 新订单/产成品库存分项、产成品存货同比、
  营业收入累计同比、PPI 同比。
- 朱格拉：扩张=投资增速上行+产能利用率走高；见顶=增速高位钝化+利用率回落；
  出清=投资转负/低位+落后产能退出增多；复苏=设备更新需求回升+信贷宽松。
  锚定：制造业固投、民间投资、机床/工业机器人产量、产能利用率、
  企业中长期贷款、美国核心资本品订单。
- 库兹涅茨：人口（25-44 岁主力）+ 新开工 + 房价 + 库存去化周期四维定位，
  分区域（一线/强二线/弱二线/三四线）标注。
- 康波：多维拼图——技术渗透率（AI/新能源 S 曲线位置）、TFP 增速、长端
  利率中枢、资本开支结构、专利密度。康波判断天然低置信度，须诚实标注。

# 字段约束（封闭集与固定映射，违反即不合规）
- direction ∈ { 回升 / 上行 / 见顶回落 / 下行 / 筑底 / 企稳 }
- confidence ∈ { 高 / 中 / 低 }
- action 格式为"倾向词——一句话逻辑"，倾向词 ∈ { 左侧布局 / 右侧跟随 /
  持有观察 / 回避 }，须综合该行业库存层、产能层、长期需求三层位置给出：
  库存与产能双底且需求不差 → 左侧布局；拐点已被数据确认 → 右侧跟随；
  景气高位或方向不明 → 持有观察；下行未止且无托底逻辑 → 回避
- phase：当前相位在周期中的位置，0-1 小数，按标准正弦波形定位：
  0=谷底，0.25=上行中点，0.5=峰值，0.75=下行中点，1=回到谷底。
  阶段与相位区间的固定映射（stage 必须落在对应区间内）：
  | 相位区间 | 基钦     | 朱格拉 | 库兹涅茨   | 康波 |
  |---------|-----------|--------|-----------|------|
  | 0 - 0.25（谷底回升） | 被动去库 | 复苏期 | 底部盘整段 | 复苏 |
  | 0.25 - 0.5（上行至峰） | 主动补库 | 扩张期 | 上行段 | 繁荣 |
  | 0.5 - 0.75（峰后回落） | 被动补库 | 见顶期 | 见顶回落段 | 衰退 |
  | 0.75 - 1（深度下行至谷） | 主动去库 | 出清期 | 下行出清段 | 萧条 |
  段内细分（三分制）：段内位置 =（phase − 区间下界）/ 0.25，
  不足 1/3 为前段，1/3 至 2/3 为中段，超过 2/3 为后段。
  stage 应带段内后缀（术语 + "（前段/中段/后段）"），且必须与 phase 一致。
  例："出清期（中段）" → phase ≈ 0.85；"被动去库（前段）" → phase ≈ 0.05；
  "萧条（后段）" → phase ≈ 0.92
- industries 必须逐一覆盖下列 24 个行业（一个不落，不得合并为一行）：
  上游：煤炭、有色（铜/铝/锂）、原油；中游：钢铁、化工、建材、光伏、锂电、
  半导体、工程机械、汽车；下游：家电、消费电子、食品饮料、纺织服装；
  地产链：房地产开发、物管、家居；TMT：AI 算力（服务器/光模块）、
  软件 SaaS、运营商；金融：银行、券商、保险。
  inventory 用基钦四阶段术语、capacity 用朱格拉四阶段术语、demand 用
  { 成长期 / 成熟期 / 衰退期 }；金融、物管等不适用库存/产能层的行业，
  该两字段填"—"；确无数据支撑的行业也须给出保守倾向（如持有观察）
  并在 summary 注明"依据薄弱"
- top3：综合推荐排名前三的投资行业，依据行业分层结果按
  "周期位置 × 证据强度 × 风险调整"排序；rank 为 1-3 名次，action 倾向词
  与 industries 中该行业的判断一致，layers 三项分别标注该行业库存层、
  产能层与长期需求位置，evidence 须为可观测的具体数据（指标 + 读数），
  risk 为该推荐的主要风险
- watchlist 恰好 5 项：需要持续跟踪的关键指标
- meta.anchors 必须四周期齐全；kind ∈ { measured / official_series / inferred }，
  kind=inferred 的周期 confidence 不得高于"中"；error_months 为该相位误差（月）
- pending_data 与 missing_data 互斥：未到发布时点写前者，已过发布日未取得写
  后者；两者都不得用上期值代替本期读数；inferred 推算值不写入 missing_data
- 行业读数覆盖：24 项中 ≥12 项 summary 含当期读数，且上游/中游关键 10 个
  （煤炭、有色、原油、钢铁、化工、建材、光伏、锂电、半导体、工程机械）必须
  覆盖；未覆盖的行业列入 weak_evidence

□ top3 恰好 3 项、watchlist 恰好 5 项、每个周期的 evidence ≥3 条
□ 每条 evidence 含"指标 + 读数 + 数据月份"
□ stage（含段内后缀）与 phase 的区间映射一致；
  direction / confidence / action 倾向词均在封闭集内
□ JSON 与正文所有周期定位结论一致
□ meta.data_sources 列明实际引用来源；数据缺口已列入 meta.missing_data
□ 已按发布日历分三类：已获取 / pending_data（未到发布时点）/ missing_data
  （应发布未取得）；pending 不得混入 missing，且不得用上期值冒充本期
□ meta.anchors 四周期齐全，kind 与推导一致；无"phase×周期长度反推起点"
  被当作已获取数据；inferred 周期 confidence ≤ 中
□ 24 行业中 ≥12 项含当期读数，上游/中游关键 10 个全覆盖；不足项已列入
  meta.weak_evidence
□ 若提供了上期 phase，已完成相位差校验（见五、使用建议 6），跳变异常已复核
```

## 二、分周期深挖提示词（按需追加，可多选）

### 2.1 基钦周期（库存周期，3-4 年）

```text
# 任务
判断当前库存周期所处象限，并做行业拆分。

# 四象限判定（核心）
以「产成品存货同比」为纵轴、「营收/新订单同比」为横轴：
主动补库=库存↑需求↑（量价齐升）；被动补库=库存↑需求↓（积压、降价压力）；
主动去库=库存↓需求↓（砍单、工业品价格承压）；
被动去库=库存↓需求↑（去化至低位、回补拐点，往往是股市前瞻买点）。

# 必查指标（优先一次取全）
1. 官方制造业 PMI（新订单、产成品库存、原材料库存、购进/出厂价格分项）
2. 工业企业产成品存货累计同比 + 营业收入累计同比（同月统计局发布）
3. PPI 同比（库存周期的价格镜像）
4. 名义 vs 实际社零增速剪刀差
5. CRB 现货指数 / 南华工业品指数
6. 港口吞吐量、铁路货运量（实物量交叉验证）

# 输出要求
1. 当前象限 + 判断依据（指标 + 读数 + 月份）
2. 本轮起点（上一轮去库底部）与已运行时长：按 S2.0 锚定表给出锚定指标、
   锚定月份与 kind；kind=inferred 须写明推算假设与误差，禁止用
   phase×3.5 年反推起点后当作实测值；并对比 3-4 年历史均值是否异常
3. 行业拆分表：| 行业 | 库存分位 | 需求方向 | 所处阶段 | 逻辑 |
   覆盖：上游资源（煤炭/有色/原油）、中游制造（钢铁/化工/建材/通用设备/
   电子）、下游消费（汽车/家电/纺织服装/食品饮料）
4. 库存周期对股市/商品的映射含义
```

### 2.2 朱格拉周期（设备投资周期，8-10 年）

```text
# 任务
判断当前设备投资/产能周期所处阶段，并做行业拆分。

# 阶段判定标准
扩张期=设备投资增速持续上行+产能利用率走高+信贷向制造业投放；

2. 行业拆分表：| 行业 | 投资增速 | 产能利用率 | 更新需求 | 所处阶段 |
   覆盖：工程机械、重卡、轨交、船舶、光伏设备、锂电设备、半导体设备、
   3C 设备（新能源与半导体因自身生命周期可能与总量错位，单独标注）
3. 区分"更新改造需求"与"产能扩张需求"的占比变化
4. 设备投资周期对中游制造板块股价的领先/滞后关系
```

### 2.3 库兹涅茨周期（建筑/地产周期，约 20 年）

```text
# 任务
判断当前建筑与房地产长周期所处阶段，分区域标注。

# 阶段判定标准（以中国为例，参照 1998-2021 上行长波）
上行段=购房主力人口扩张+新开工趋势向上+房价长期上行；

# 必查指标
1. 人口面：出生人口、25-44 岁购房主力人口规模及预测、城镇化率增速

2. 量：商品房销售面积（累计同比 + 相对历史峰值回撤）、新开工面积、
   施工/竣工剪刀差
3. 价：70 城房价指数（新房/二手分开）、二手房挂牌价与成交量
4. 库存：广义库存去化周期（含在建未售）

# 输出要求
1. 中国库兹涅茨周期当前阶段——下行是否接近尾声须给数据依据，不接受理论预设
2. 区域分化表：| 区域 | 人口流向 | 库存去化周期 | 房价趋势 | 阶段定位 |
   覆盖：一线 / 强二线 / 弱二线 / 三四线（区分人口流入与流出型）
3. 国际对照：美国当前阶段（新屋开工中枢、成屋库存、30 年房贷利率下的

4. 对居民资产负债表、消费倾向、地方财政的结构性影响
5. 区分"总量长周期下行"与"结构性机会（城中村改造/保障房/核心城市改善）"
```

### 2.4 康德拉季耶夫长波（50-60 年）

```text
# 任务
判断当前康波（技术长波）所处阶段，以及向下一阶段切换的迹象。

# 背景锚点（用于校准，必须用数据验证）
主流划分：第一波蒸汽（1780s-1840s）、第二波铁路钢铁（1840s-1890s）、
第三波电气化工（1890s-1940s）、第四波汽车石化（1940s-1980s）、
第五波信息技术（1980s-2020s）。当前主流观点认为第五波处于萧条期向
第六波（AI/新能源/生物科技）过渡——请用数据验证或修正。

# 观测维度（长波无法用单一月度指标判断，需多维拼图）
1. 技术渗透率：AI（大模型商用收入、token 消耗增速、企业采用率）、
   新能源（光伏/风电渗透率、电动车渗透率 S 曲线位置）
   ——渗透率 10%-50% 为加速期，>60% 后增速自然回落
2. 全要素生产率（TFP）增速：技术革命是否已兑现为生产率抬升
3. 长期利率中枢：30-50 年维度美债收益率方向（长波的价格表达）
4. 资本开支结构：科技巨头 Capex 占比、研发投入/GDP
5. 专利与颠覆式创新密度
6. 黄金与实际利率的长期背离（萧条期特征之一）

# 输出要求
1. 当前康波阶段 + 置信度（康波判断天然低置信度，须诚实标注）
2. 第五波对生产率的贡献是否完成；第六波候选技术哪个最可能主导
3. 当前是"旧技术红利耗尽+新技术尚未规模兑现"的青黄不接，还是新技术
   已开始系统性抬升生产率
4. 对大类资产的含义（历史规律：萧条期利好黄金/长久期债，复苏早段
   利好新技术股权资本）
```

## 五、使用建议

1. **单次提问获得全景**：直接使用【总提示词】，填入当前时点与地区。
2. **深入某个周期**：在总提示词之后追加对应的深挖模块（二/三），可多选。
3. **可视化渲染**：将 AI 输出的 JSON 数据块粘贴到 `dashboard.html` 底部
   「导入数据」区，报告页（周期卡片/波形叠加/行业热力图/TOP3）整体刷新；
   页面内置提示词模板一键复制，也可直接在页面内取用。schema 2.1 的新增字段
   （pending_data / anchors / weak_evidence）为可选增强，dashboard 向后兼容
   2.0 数据。
4. **投资应用**：重点看总览中的"错位/共振"状态与行业分层表——
   错位期选行业阿尔法，共振期做资产贝塔。
5. **频率建议**：基钦每 1-2 个月复核；朱格拉每季度；库兹涅茨与康波每年。
   出报告尽量选在发布窗口之后（月初 2 日后、月末 PMI 发布后）；若提前出，
   未发布项一律记为 pending_data，发布后升 revision 补录。
6. **跨期一致性校验**：与上次定位相比阶段跳变时，先做相位差检验：
   相位差 =（新 phase − 旧 phase + 1）对 1 取余（处理跨谷回绕，
   如 0.95 → 0.05 实际前进 0.1 个周期）；若余数大于 0.5 取 1 − 余数。
   合理间隔 ≈ 相位差 × 周期长度。实际间隔明显偏短即为矛盾信号，
   优先复核数据口径与需求方向解读，而非直接采信新结论。
7. **警惕局限**：所有周期长度是历史统计而非物理定律，全球化与政策逆周期
   调节会拉长或压平周期。要求 AI 输出置信度，正是为了对抗
   "理论先行、数据迁就"的分析陷阱。
