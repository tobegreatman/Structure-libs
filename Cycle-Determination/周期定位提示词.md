## 二、分周期深挖提示词

### 2.1 基钦周期（库存周期，3-4 年）

```text
# 任务
基于最新数据，判断当前库存周期处于哪个阶段，并做行业拆分。

# 四象限判断标准（核心）
以「工业企业产成品存货同比」为纵轴、「营收/新订单同比」为横轴：
- 主动补库：库存↑ + 需求↑（量价齐升，PMI 新订单持续高于 50 且环比走强）
- 被动补库：库存↑ + 需求↓（库存积压，开始出现降价压力）
- 主动去库：库存↓ + 需求↓（企业砍单去库，工业品价格承压）
- 被动去库：库存↓ + 需求↑（库存去化至低位，迎来回补拐点，往往是
  股市前瞻买点）

# 必查指标清单
1. 中国官方制造业 PMI（重点看：新订单、产成品库存、原材料库存、
   购进价格/出厂价格分项）
2. 工业企业产成品存货累计同比（国家统计局）
3. 营业收入累计同比（判断需求侧）
4. 名义社零 vs 实际社零增速剪刀差
5. PPI 同比（库存周期的价格镜像，一般领先或同步于库存同比）
6. CRB 现货指数 / 南华工业品指数
7. 港口吞吐量、铁路货运量（实物量交叉验证）

# 输出要求
1. 明确当前所处象限，给出判断依据
2. 标注本轮库存周期起点（上一轮去库底部），推算周期运行时长，
   与 3-4 年历史均值对比是否异常
3. 行业拆分表：
   | 行业 | 库存分位 | 需求方向 | 所处阶段 | 逻辑 |
   覆盖：上游资源（煤炭/有色/原油）、中游制造（钢铁/化工/建材/
   通用设备/电子）、下游消费（汽车/家电/纺织服装/食品饮料）
4. 判断库存周期对股市/商品的映射含义
```

### 2.2 朱格拉周期（设备投资周期，8-10 年）

```text
# 任务
基于最新数据，判断当前设备投资/产能周期所处阶段，并做行业拆分。

# 阶段判断标准
- 扩张期：设备投资增速持续上行 + 产能利用率走高 + 信贷向制造业投放
- 见顶期：投资增速高位钝化 + 产能利用率见顶回落 + 新增订单放缓
- 出清期：投资增速转负/低位 + 企业盈利下滑 + 落后产能退出并购增多
- 复苏期：设备更新需求回升 + 更新改造投资占比上升 + 信贷条件宽松

# 必查指标清单
1. 制造业固定资产投资累计同比（总量）
2. 民间固定资产投资增速（内生投资意愿）
3. 金属切削机床产量同比（传统设备投资代理变量）
4. 工业机器人产量同比（自动化投资）
5. 挖掘机/重卡销量（工程机械与运输设备，兼看保有量与更新周期）
6. 工业产能利用率（判断产能过剩/紧张）
7. 企业中长期贷款增速（投资资金来源）
8. 通用设备/专用设备制造业营收与利润增速
9. 美国：核心资本品订单（nondefense capital goods excluding aircraft）
   ——全球朱格拉周期的外部锚

# 输出要求
1. 明确当前阶段，标注本轮朱格拉周期起点（上一轮出清底部）
2. 行业拆分表：
   | 行业 | 投资增速 | 产能利用率 | 更新需求 | 所处阶段 |
   覆盖：工程机械、重卡、轨交设备、船舶、光伏设备、锂电设备、
   半导体设备、3C 设备（注意：新能源与半导体因产业自身生命周期，
   可能与整体朱格拉周期错位，需单独标注）
3. 区分"更新改造需求"与"产能扩张需求"的占比变化
4. 给出设备投资周期对中游制造板块股价的领先/滞后关系
```

### 2.3 库兹涅茨周期（建筑/地产周期，约 20 年）

```text
# 任务
基于最新数据，判断当前建筑与房地产长周期所处阶段，分区域标注。

# 阶段判断标准（以中国为例，参照 1998-2021 上行长波）
- 上行段：购房主力人口（25-44 岁）规模扩张 + 新开工长期趋势向上 +
  房价长期上行 + 地产链 GDP 占比提升
- 见顶回落段：人口拐点出现 + 新开工历史大顶确认 + 库存开始累积
- 下行出清段：新开工累计降幅达 40%+ + 房价深度调整 + 出险与出清
- 底部盘整段：销售/新开工在低位企稳 + 政策转向长效机制 +
  保障房/城市更新成为新变量

# 必查指标清单
1. 人口面：出生人口、自然增长率、25-44 岁购房主力人口规模及预测、
   城镇化率及其增速（增速二阶拐点比水平更重要）
2. 量：商品房销售面积（年度累计同比 + 绝对水平相对历史峰值的回撤幅度）、
   新开工面积、施工/竣工面积剪刀差
3. 价：70 城房价指数（新房/二手分开）、二手房挂牌价与成交量
4. 库存：广义库存去化周期（含在建未售）
5. 金融：居民中长期贷款、房贷利率、首付比例等政策变量
6. 投资：房地产开发投资完成额累计同比、地产链（建材/家电/家具）零售

# 输出要求
1. 明确中国库兹涅茨周期当前阶段，判断长周期下行是否接近尾声、
   还是仍在途中（给出依据，不接受理论预设）
2. 区域分化标注表：
   | 区域 | 人口流向 | 库存去化周期 | 房价趋势 | 阶段定位 |
   覆盖：一线城市 / 强二线 / 弱二线 / 三四线（区分人口流入与流出型）
3. 国际对照：美国当前库兹涅茨周期阶段（新屋开工长期中枢、
   成屋库存、30 年期房贷利率影响下的购买力、千禧一代购房需求）
4. 判断地产长周期对居民资产负债表、消费倾向、地方财政的结构性影响
5. 明确"总量长周期下行"与"结构性机会（城中村改造/保障房/核心城市
   改善需求）"的区分
```

```text

判断当前康波（技术长波）所处阶段，以及向下一阶段切换的迹象。

# 背景锚点（用于校准，但必须用数据验证）
主流划分：第一波（蒸汽，1780s-1840s）、第二波（铁路钢铁，
1840s-1890s）、第三波（电气化工，1890s-1940s）、第四波（汽车石化，
1940s-1980s）、第五波（信息技术，1980s-2020s）。
当前主流观点认为第五波处于萧条期向第六波（AI/新能源/生物科技）
过渡阶段——请用数据验证或修正这一判断。

# 观测维度（长波无法用单一月度指标判断，需多维拼图）
1. 技术渗透率：AI（大模型商用收入、token 消耗量增速、企业采用率）、
   新能源（光伏/风电渗透率、电动车渗透率 S 曲线位置）
   ——渗透率 10%-50% 区间为渗透加速期，>60% 后增速自然回落
2. 全要素生产率（TFP）增速：美国 BLS、中国宏观杠杆率研究中心数据，
   判断技术革命是否已兑现为生产率抬升
3. 长期利率中枢：30-50 年维度美债收益率的方向（长波的价格表达）
4. 资本开支结构：科技巨头 Capex 占比、研发投入/GDP
5. 专利与颠覆式创新密度
6. 黄金与实际利率的长期背离（萧条期特征之一）

# 输出要求
1. 给出当前康波阶段判断（繁荣/衰退/萧条/复苏）+ 置信度
   （康波判断天然低置信度，须诚实标注）
2. 判断第五波（信息技术）是否已完成对生产率的贡献，第六波候选技术
   （AI/核聚变/生物科技/新能源）哪个最可能成为主导
3. 判断当前是"旧技术红利耗尽 + 新技术尚未规模兑现"的青黄不接阶段，
   还是新技术已开始系统性抬升生产率
4. 给出康波阶段对大类资产的含义（历史规律：萧条期利好黄金/长久期债，
   复苏期早段利好新技术股权资本）
```

## 六、使用建议

1. **单次提问即可获得全景**：直接使用【总提示词】，填入当前日期与地区。
2. **深入某个周期**：在总提示词之后追加对应的分周期深挖提示词。
3. **可视化渲染**：将 AI 输出的 JSON 数据块粘贴到 dashboard.html
   页面底部的"导入分析数据"区域，仪表盘（周期卡片/波形叠加/行业热力图）
   会整体刷新为最新判断。
4. **投资应用**：重点看总览仪表盘中的"错位/共振"状态与行业分层表
   ——错位期选行业阿尔法，共振期做资产贝塔。
5. **频率建议**：基钦周期每 1-2 个月复核一次；朱格拉每季度；
   库兹涅茨与康波每年复核一次即可。
6. **跨期一致性校验**：与上次定位相比阶段发生跳变时，先做相位差检验：
   相位差 =（新 phase − 旧 phase + 1）对 1 取余（处理跨谷回绕，
   如 0.95 → 0.05 实际是前进 0.1 个周期）；若余数大于 0.5，
   取 1 − 余数。合理间隔 ≈ 相位差 × 周期长度（基钦 3.5 年下，
   半个周期约 21 个月）。实际间隔明显偏短即为矛盾信号，优先复核
   数据口径与需求方向解读（被动去库 = 订单回升，被动补库 = 订单回落，
   方向相反必有一错），而非直接采信新结论。
7. **警惕提示词的局限**：所有周期长度（3-4/8-10/20/50-60 年）是历史统计
   而非物理定律，全球化、政策逆周期调节会拉长或压平周期。要求 AI
   输出置信度，正是为了对抗"理论先行、数据迁就"的分析陷阱。
