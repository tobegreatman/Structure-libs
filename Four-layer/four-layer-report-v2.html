四层决策链路

  1. L1 宏观判据加权 → 仓位档位 + 久期取向 + 周期阶段
  2. L2 市场情绪系数 + 温度 + 抱团度 → 节奏校准与仓位微调
  3. L3 行业景气评分 × 交易位置 → Top3 赛道与规避清单
  4. L4 公司三高评分 + 估值定位 + 风控 → 个股落地
