# 宏观指标解读 · 提示词模板 v2

> **本文件即执行指令：收到 = 立即开始执行，无需用户再说任何话。**
>
> 你（AI）收到本文件后，按第 2 章时间粒度定位期数，按第 3 章数据源注册表联网取数，按第 4 章框架完成分析，按附录 A 契约输出 JSON。
>
> **第一条回复 = 数据获取说明 + 完整 JSON 报告**，禁止任何"已收到 / 待命 / 请确认"式开场。
>
> 唯一例外：你确实没有任何联网工具时，用一句话说明后停止——**严禁用训练记忆编造数据**。

## 第 0 章 · 执行铁律

1. **数据必须真实**：所有数字必须来自本次联网结果，逐项标注「来源 + 发布日期」。取不到的标「缺失」，不得编造。
2. **三值齐全**：关键数据同时报告「公布值 / 市场一致预期 / 前值」。预期值取不到就填 `null`，禁止用公布值冒充预期值。
3. **多源核对**：关键数字至少两个独立来源确认；官方统计机构 / 央行 > 专业终端 > 权威财经媒体，降级时注明。
4. **先贴标签再解读**：每个数据先声明它是领先 / 同步 / 滞后指标，再展开分析。
5. **拒绝精确点位**：只输出方向、概率、区间，禁止"下月 CPI 2.3%"式单点预测或"立即买入"式指令。

## 第 1 章 · 执行流程总览

```
第 1 步 · 定位：按第 2.3 节发布日历锚点，先确定各指标「最新已发布期数」，避免空搜

```

默认参数：国家 = 中国（用户指定其他国家时加挂 3.2 ⑬ 美国组）；时间范围 = 最近 6 个月。

## 第 2 章 · 时间粒度与数据窗口

### 2.1 四级时间粒度表（科学取数口径）

宏观指标天然分布在不同频率上，**必须按指标自身的频率选择取数口径**，禁止用日频波动解读月频趋势、用单月读数否定季频结构：

| 粒度 | 指标 | 取数口径 |
|------|------|----------|
| **日频**（政策与市场价） | DR007、NCD(1Y)、10Y/2Y 国债收益率、人民币中间价、美元指数 DXY、中美 10Y 利差 | 最新交易日读数 + 近 30 日区间（均值/高/低） |
| **周频**（高频探针） | 30 城商品房成交面积、两融余额、A 股新开户数 | 最新周值 + 近 4 周方向 |
| **月频**（核心宏观） | PMI（含新订单/生产/就业/库存分项）、CPI/核心 CPI/PPI、社融/M2/M1、工业增加值、社零、出口、工业企业产成品存货 | 最新月 + 近 6 个月序列（边际趋势） |
| **季频**（确认结构） | GDP 及支出法四分项、国际收支 | 最新季；用户要求季报时加挂 GDP 三问（4.11） |

### 2.2 三层分析窗口

1. **近 6 个月**：边际趋势与拐点判断（二阶解读的主战场）。
2. **近 3 年（默认分位基准）**：历史分位计算窗口，`percentile` 与 `baseline` 必须配套给出。
3. **近 10 年（极端参照）**：判断是否处于极端区间（前/后 15%）。

### 2.3 发布日历锚点（先定位期数，再取数）

| 指标 | 发布时间锚点 |
|------|-------------|
| 官方制造业 PMI | **当月最后一天** 9:30（如 9 月 PMI 于 9-30 发布） |
| 财新制造业 PMI | 次月 1 日前后 |
| CPI / PPI | 次月 9 日 9:30 |
| 进出口（美元计价） | 次月 7 日前后 |
| 金融数据（社融 / M2 / 信贷） | 次月 10-15 日 |
| 经济组合包（工业增加值 / 社零 / 投资 / 失业率） | 次月 15-17 日 |
| 70 城房价 | 次月 15-17 日 |
| LPR 报价 | **每月 20 日** 9:00 |
| 工业企业利润 / 产成品存货 | 次月 27 日前后 |
| 财政收支 / 税收 | 次月 17-20 日前后 |
| GDP | 季后 15-20 日（1 / 4 / 7 / 10 月） |

| CFETS 汇率指数 | 每周五 |
| 30 城地产成交 | 每周（克而瑞 / Wind 转载） |

用法：先按当天日期推算每个指标应到的最新期数，再逐项取数；若实际发布晚于锚点，说明取上一个月值并注明。

### 3.3 防限流批量取数协议（五条）

1. **直连优先，搜索兜底**：3.2 表中已知聚合页直接打开抓取原文；全文搜索引擎只用于期数定位与直连失败兜底，**全文搜索全程 ≤ 8 次**。
2. **站点聚合批量**：每站 1-2 个聚合页覆盖全部所属指标（统计局 1 页 + 央行 1 页 + 货币网 1 页 + 中债 1 页 ≈ 拿到 80% 数据），**总外部读取控制在 20 次以内**。
3. **同站串行，站间不轰炸**：同一站点页面连续读取不超过 3 次；不同站点之间自然间隔，避免高频并发请求单一域名。
4. **降级链每级只试 1 次**：S → A → B 逐级降级；同一指标累计失败 2 次即标「缺失」继续下一项，**禁止对单一来源反复重试**。
5. **即读即记，一页复用**：每次读取立即记录「值 / 来源 / URL / 发布日期」；同一页面的多指标数据全部复用（如央行报告页一次拿全社融+M2+M1+信贷四组数据），sources 中注明。

## 第 4 章 · 信息分析框架（对获取到的数据逐项执行）

> 每张 SOP 卡 = 固定分析动作 + 防坑红线。执行到对应指标时完整走完卡内动作。

### 4.1 CPI / PPI · 通胀三维

- 拆构成：核心 CPI 趋势 vs 猪价/食品扰动；单月跳升若主要来自猪价，必须明说"这不算通胀信号"。
- 传导判断：PPI→CPI 传导（2-4 个季度时滞）处于进行中 / 中断 / 反向？
- **量化传导估算（强制）**：给出 PPI→CPI 历史平均传导时滞（季度数），按当前 PPI 斜率推算未来 CPI 回升区间（如"2-3 季度后 CPI 有望回升至 1.0-1.5%"），标注可信度（高/中/低）。
- 剪刀差组合：PPI 高 CPI 低 = 企业利润挤压；双高 = 全面通胀；双低 = 通缩风险。
- 红线：禁止只看 CPI 总数下通胀结论；禁止只报剪刀差不报传导路径。

### 4.2 PMI · 库存周期定位

- 本质是扩散指数，49.9 与 50.1 无本质区别——禁止"跌破荣枯线 = 崩溃"式渲染。
- 新订单 vs 生产剪刀差 → 领先生产 1-2 个月，指向补库酝酿还是去库延续。
- 原材料库存 + 产成品库存 → 四阶段定位（主动补 / 被动补 / 主动去 / 被动去）。
- **软硬交叉验证（强制）**：PMI 库存分项（软调查）必须与工业企业产成品存货同比（硬统计，3.2 ⑫）对照，方向一致才可信；持续背离必有故事。
- **历史分位（强制）**：库存周期定位必须给出历史分位（0=主动去库极端底部，100=主动补库极端顶部）。
- 官方 vs 财新背离 → 描述大中小企业分化图景。

### 4.3 社融 / M2 · 四象限

- 社融升 + M2 稳 = 实体回暖（最积极）；双升 M2 更快 = 金融空转；社融弱 M2 升 = 只存不借（资产负债表衰退特征）；双降 = 信用收缩。
- 两支温度计：居民中长贷 = 地产；企业中长贷 = 资本开支。看剔除政府债后的"市场化社融"增速。
- 领先性：社融拐点领先经济景气 2-3 个季度。
- 红线：M2 高增 ≠ 放水，必须核对组合后再说。

### 4.4 利率 · 三层瀑布验证

- 三层：政策利率/准备金（源头）→ DR007/Shibor/国债收益率（批发价）→ LPR/房贷/企业贷（实体价）。
- **批发价层必检两项（强制）**：① DR007 7 日均值与 7 天逆回购政策利率的利差（bp）——资金面松紧的水银柱；② 同业存单（NCD）1 年期发行利率（%）——银行负债成本，领先 LPR 1-2 个月。缺任一项批发价层判定作废。
- 逐层判定通 / 不通；断流时指出断点与原因假设（银行风险偏好 / 实体需求 / 时滞）。
- 红线：禁止"降息 = 放水成功"的单层确认。

### 4.5 收益率曲线

- 短端读央行态度，长端读增长通胀预期，命名当前形态（正常 / 走平 / 倒挂 / 牛陡 / 熊陡）。
- 倒挂 = 历史上 6-24 个月后衰退高命中，但"是地震预警不是时刻表"——只校准概率，不给时点。
- 输出风险敞口建议：显著倒挂 → 降久期备现金；正常陡峭 → 顺周期资产可进攻。调敞口，不择时。

### 4.6 汇率三问

- 一问什么在动：对美元 / CFETS 篮子是否背离（对美元贬但篮子稳 = 动的是美元）。
- 二问为什么动：利差 / 贸易顺差 / 预期，哪个主导，证据是什么。
- **归因必检旁证（强制）**：① 中美 10Y 国债利差（中国−美国，bp）——汇率核心解释变量；② 美元指数 DXY——判断"动的是美元还是人民币"。两项必须引用，否则归因沦为叙事，作废。
- 三问传导：出口链受益、进口成本受损、外债主体承压，逐一列出。
- 校准：适度走弱是经济自带减震器，不是国力记分牌。

### 4.7 领先 / 滞后标签表

| 组别 | 指标 |
|------|------|
| 领先 | PMI 新订单、社融、收益率曲线、居民中长贷 |
| 同步 | 工业增加值、GDP、社零、发电量 |
| 滞后 | 失业率、CPI、库存 |

用法：领先组定位阶段 → 同步组确认 → 滞后组排雷，顺序不能反。**滞后的坏消息可能是底部特征**。

### 4.8 二阶解读（每个指标强制三段式）

- 一阶（是什么）：实际还是名义？基数效应？分项谁驱动？
- 二阶（边际与预期差）：相对预期意外多大？趋势延续还是拐点？"连续三季 4.8% 后首升到 5%"比孤立的 5% 重要十倍。
- 三阶（政策与市场反应）：会怎么改变央行反应函数？市场叙事被确认还是打破？反向检查：极好可能见顶，极差可能见底。
- 红线：数据好 ≠ 资产涨；只写一阶的输出作废。

### 4.9 交叉验证（对最重要的 1-2 个数据执行）

- 用 3.2 ⑨ 的旁证数据（用电量 / 税收）对照官方增长叙事。
- 软硬对照：PMI（软调查）vs 工业增加值（硬统计）方向是否一致，持续背离必有故事。
- 输出三角验证矩阵：原数据 + 旁证一 + 旁证二，各自方向、是否咬合、偏差方向与量级。

### 4.10 周期定位仪表盘（月报收尾必做）

- 四维：估值分位（3.2 ⑩）、信贷（社融 + 利差）、情绪（融资余额 / 新开户）、本轮周期运行时长。
- 每维标注历史分位与是否极端（前/后 15%）；**≥3 项极端且同向才触发行动建议，否则明示"信号不足，维持现状"**。
- **分位与基准双标（强制）**：每个维度必须同时给出①历史分位数（0-100）和②分位计算基准说明（如"2008 年以来沪深300 PE"、"2015 年以来社融增速"，分位窗口默认近 3 年、极端参照近 10 年，见 2.2）。禁止主观判断"极端"而不给分位和基准。
- 必须给出证伪条件：出现什么信号说明本次定位错了。
- 红线：单看估值会掉进"便宜更便宜"的坑，必须多指标咬合。

### 4.11 GDP 三问（季报 / 含季度数据时执行）

- ① 价格幻觉：实际 vs 名义，平减指数正负？② 基数幻觉：去年同期多少？两年平均多少？③ 结构幻觉：支出法四分项谁驱动、可持续吗？
- 定位声明：GDP 是滞后确认指标，只用于确认结构，不用于预判下月。

## 第 5 章 · 报告输出要求（JSON 数据契约模式）

> **架构原则：数据与视图分离。** 提示词只输出 JSON 数据，不直接写 HTML。HTML 由 `report-template.html` 读取 JSON 自动渲染。

1. 开头五行内交代：本次联网执行情况（共几次搜索 / 直连读取、数据截至期数）、数据完整度（缺失项列表）。
2. **唯一输出产物 = 符合 `schema/report.schema.json` 契约的 JSON 对象**（见附录 A 模板）。
3. 若你有写文件能力：
