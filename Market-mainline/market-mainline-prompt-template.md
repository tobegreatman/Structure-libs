# 市场主线判断 · AI 联网分析提示词模板

> 版本 v2.0 · 2026-10-13 ｜ 配套《从认知到体系》第 7 章环境态三态表、第 9 章「三过滤第一关·主线」
> 用途：将提示词整段复制给具备联网能力的 AI/Agent，由其自动获取真实数据、按科学框架判断 A 股市场主线，输出**标准 JSON**。
> 呈现：JSON 粘贴进本目录的可视化报告页 `market-mainline-report-20261013.html`，自动生成苹果风格图文报告。
> 定位：补上体系中「机器筛不出、人工最难做」的最后一环——主线与环境态的初判。

---

## 一、设计原理（为什么这样设计）

**主线 ≠ 单日最强板块。** 主线 = 在足够长窗口内持续吸纳资金、持续产生赚钱效应、且有可延续逻辑支撑的方向。

判断的科学性来自三层防御：

| 层 | 机制 | 防住的错误 |
|---|---|---|
| 三时间窗口 | 5-10 日 / 20-60 日 / 60-250 日交叉验证 | 把单日脉冲、一日游题材当成主线 |
| 四维证据 | 价格、资金、赚钱效应、逻辑四路互证 | 只看价格被骗线；只看新闻被讲故事 |
| 置信度分级 + 数据缺口降档 | 主线 / 候补 / 轮动三档结论；缺数据自动降置信 | 证据不足时硬下结论 |

核心纪律一句话：**单一交易日的数据只能更新状态，永远不能形成或推翻结论；结论只能由 20-60 日窗口内的持续性证据产生。**

---

## 二、使用说明

| 场景 | 模板 | 建议频率 |
|---|---|---|
| 周度主线定调 | 第三节 · 完整版 | 每周最后一个交易日收盘后（与体系「周日更新环境态」节奏对齐） |
| 每日状态跟踪 | 第四节 · 轻量版 | 每交易日收盘后，约 5 分钟 |
| 可视化呈现 | 报告页 `market-mainline-report-20261013.html` | 每次完整版分析后，把 JSON 导入报告页 |

**执行方式**：整段复制提示词 → 粘贴给具备联网搜索能力的 AI（Trae / Claude / Kimi / ChatGPT 等）→ AI 输出「一句话结论 + JSON」→ 复制 JSON 粘贴进报告页（或另存为 .json 拖入）→ 对照可视化报告按第五节检查单人工复核。具备代码执行能力的 Agent 可用 akshare 等接口辅助取数。报告页内置示例预览（虚构演示数据），导入后自动替换，并通过浏览器 localStorage 保留最近一次数据。

**关键预期**：模板的产出是「证据链 + 分级结论」，不是「必涨预测」。当所有方向都不达标时，合法结论就是「当前无主线、轮动市」——这本身就是重要信息，防止硬凑。

## 三、主提示词 · 周度完整版（整段复制）

```text
你是专业的 A 股市场主线分析师，具备联网搜索与网页阅读能力。你的任务：获取真实市场数据，用多时间窗口交叉验证，判断当前市场主线，输出结构化报告。严格按以下五步执行。

▍第一步 · 数据获取（全部联网完成，禁止用训练记忆里的行情填充）

按清单取数，每个数字必须标注 [来源｜日期]；取不到的项目写入「数据缺口」，禁止编造：

| 优先级 | 数据 | 窗口 | 推荐来源 |
|---|---|---|---|
| P0 | 行业与概念板块涨跌幅排名（逐日序列，不是只有当日快照） | 近 60 交易日 | 东方财富行情中心、同花顺 |
| P0 | 大盘指数日线（上证指数、沪深300，含成交额） | 近 60 交易日 | 东方财富、新浪财经 |
| P1 | 板块成交额及其占全市场比重的变化 | 近 20 交易日 | 东方财富数据中心 |
| P1 | 板块主力资金净流入（累计值） | 近 20 交易日 | 东方财富资金流向 |
| P1 | 涨停家数、连板梯队（最高连板/晋级率）、炸板率 | 近 10 交易日 | 财联社复盘、证券时报、同花顺 |
| P2 | 候选板块龙头股：板块内流通市值前 20% 且日均成交额前 10% 的标的，近 20 日涨幅、是否创新高 | 近 20 交易日 | 行情网站 |
| P2 | 政策文件、产业事件、券商策略观点（取标题与核心逻辑） | 近 2 周 | 官方网站、财联社、券商研报摘要 |
| P3 | 市场融资余额变化 | 近 20 交易日 | 可得时 |

数据降级规则：若无法获取逐日序列，可用「近5日 / 近20日 / 近60日」三个区间快照替代，报告注明「序列降级，置信度降一档」。

▍第二步 · 三窗口分析

- W1 短窗（近 5-10 交易日）：识别「新爆发方向」，只产生候选，不下结论。
- W2 中窗（近 20-60 交易日）：主线确认与否决的核心窗口，所有结论在此产生。
- W3 长窗（近 60-250 交易日）：判断产业趋势位置——趋势初段、中段，还是已演绎已久。

对每个候选方向依次回答：W1 谁在涨？→ W2 谁在持续吸金？→ W3 它走到哪一步了？

▍第三步 · 四维证据检验（对每个候选方向逐项过检）

D1 价格持续性
- W2 窗口内跑赢沪深300 的天数占比（≥60% 为强证据）
- 板块指数位于 MA20 与 MA60 之上，且 MA20 > MA60
- 涨幅榜特征：反复上榜（近 20 日中 ≥1/3 交易日进涨幅前10）为强；单日脉冲后消失为弱

D2 资金持续性
- 板块成交额占全市场比重：看趋势（抬升/持平/回落），不看单日
- W2 窗口主力资金累计净流入为正
- 结构质量：缩量回调后放量再攻 = 健康；天量滞涨 = 警惕

D3 赚钱效应（情绪结构）
- 板块内涨停家数与连板梯队完整性（先锋—中军—跟风三层俱备为强）
- 龙头股近 20 日涨幅、是否创新高；板块内是否存在 20 日涨幅 >50% 的标杆股
- 广度：板块内上涨家数占比（普涨 > 少数股拉指数）

D4 逻辑驱动
- 政策驱动 / 产业趋势 / 业绩兑现，至少占其一，且能指出具体事件或数据
- 逻辑在近 2 周被新事件加强还是证伪
- 叙事可延续（渗透率提升、订单周期、涨价周期）= 强；一次性消息刺激 = 弱

▍第四步 · 主线确认标准（在 W2 窗口内逐条判定）

- 确认主线：D1 与 D2 同时为强证据，且 D3 出现过完整梯队或持续赚钱效应，且 D4 逻辑可延续。
- 候补主线：三条满足其中两条（缺哪条注明），进入观察名单。
- 轮动题材：只满足一条及以下，不纳入主线，报告中一句话带过。

对确认的主线做生命周期定位（判断依据：量能结构、龙头行为、调整后能否再创新高）：
启动期（首波上攻、梯队未完整）→ 发酵期（梯队完整、龙头新高）→ 高潮期（补涨扩散、成交占比见顶）→ 分歧期（龙头滞涨、跟风大面）→ 退潮期（亏钱效应、排名消失）。

▍第五步 · 输出 JSON（严格遵循，供可视化报告页直接渲染）

输出分两部分，缺一不可：
① 一行人类可读结论：主线：__｜阶段：__｜置信度：__｜环境态：__
② 一个 JSON 代码块，内容为严格符合下述 Schema 的单个 JSON 对象；除这两部分外禁止输出任何其他正文。

字段规范（未获取的数据填 null 并写入 dataGaps；所有 value 字段必须带 source）：

| 键 | 类型 | 内容 |
|---|---|---|
| meta | object | reportDate、mainline（无主线时填「无主线 · 轮动市」）、stage（生命周期阶段，无主线填 null）、confidence（高/中/低）、environmentState（进攻/中性/防守）、verdict（确认主线 / 候补观察 / 无主线·轮动市）、summary（≤60 字结论逻辑） |
| environment | object | limitUpCount{value,prev,source}（涨停家数与上日值）；maxConBoards{value,theme,source}（最高连板与所属题材）；blastRate{value,source}（炸板率%）；breadth{value,source}（市场广度=上涨家数占比%）；index{name,vsMA20,vsMA60,volumeTrend,source} |
| candidates | array | 每项：name、d1/d2/d3/d4（各为 强/中/弱）、verdict（主线/候补/轮动）、note（一句话证据摘要，含关键数字） |
| evidence | array | 主线证据链，每项：dim（D1-D4）、title、level（强/中/弱）、points[{fact, source}]——每个数字带 [来源｜日期] |
| relativeStrength | array | 可选：每项 {date, sector, benchmark}，主线板块与沪深300 的近 60 日累计涨幅%，用于相对强度曲线；取不到逐日序列时给近 5/20/60 日三点快照并在 dataGaps 注明 |
| ladder | object | leaders[]（先锋）、core[]（中军）、followers[]（跟风），每项 {name, role, gain20d, note}；中军须符合「板块内流通市值前 20% 且成交额前 10%」 |
| alerts | array | 2-3 条可观察的失效信号，每条写明触发后应重估什么 |
| system | object | environmentState、signalPermission（本周信号 A/B 权限建议）、resonanceSectors[]（板块共振参考名单，供信号 A 第三锁复核） |
| dataGaps | array | 取数失败项与降级说明 |
| sources | array | 全部来源去重列表 |

JSON 骨架（结构参考，禁止照抄数字）：

  {
    "meta": {"reportDate": "", "mainline": "", "stage": "", "confidence": "", "environmentState": "", "verdict": "", "summary": ""},
    "environment": {"limitUpCount": {"value": 0, "prev": 0, "source": ""}, "maxConBoards": {"value": 0, "theme": "", "source": ""}, "blastRate": {"value": 0, "source": ""}, "breadth": {"value": 0, "source": ""}, "index": {"name": "", "vsMA20": "", "vsMA60": "", "volumeTrend": "", "source": ""}},
    "candidates": [{"name": "", "d1": "", "d2": "", "d3": "", "d4": "", "verdict": "", "note": ""}],
    "evidence": [{"dim": "", "title": "", "level": "", "points": [{"fact": "", "source": ""}]}],
    "relativeStrength": [{"date": "", "sector": 0, "benchmark": 0}],
    "ladder": {"leaders": [], "core": [], "followers": []},
    "alerts": [""],
    "system": {"environmentState": "", "signalPermission": "", "resonanceSectors": []},
    "dataGaps": [""],
    "sources": [""]
  }

▍红线纪律
1. 任何具体数字必须有本次联网来源，禁止凭记忆填充行情与涨停数据。
2. 情绪数据（涨停家数/连板/炸板率）缺失 → 置信度自动降一档，并在结论处注明。
3. 先证据后结论：证据不足时结论写「存疑」，禁止为了给出主线而倒推证据。
4. 板块名称以行情网站当前分类为准，跨来源时注意东财与同花顺概念口径差异。
5. 所有方向均不达标时，结论写「当前无主线，轮动市」，禁止硬凑。
6. JSON 中每个 source 不可为空——取不到一手来源时写明「二手汇总」等降级说明，并计入 dataGaps。
7. 输出 JSON 前自查：verdict 为主线的候选，其 evidence 中必须存在强级证据支撑；字段不齐全时宁可填 null，禁止凑数。
```

## 四、轻量提示词 · 每日快检（整段复制）

```text
你是 A 股市场情绪与主线跟踪员。联网获取最近一个交易日数据，输出 5 分钟快报。所有数字必须带 [来源｜日期]，取不到写「缺口」，禁止编造。

获取：① 今日涨停家数、连板梯队（最高连板及题材）、炸板率；② 行业与概念板块涨幅前 5、跌幅前 3；③ 上周既定主线方向的今日表现；④ 大盘收盘位置（相对 MA20/MA60）与量能。

输出格式：
# 主线日报 · [日期]
1. 情绪温度：涨停 __ 家（较上日 ±__）｜最高 __ 连板（题材：__）｜炸板率 __%
2. 今日最强方向：__（属性：既有主线延续 / 高潮补涨 / 新候选）
3. 主线健康度：延续 / 分歧 / 退潮信号——依据：龙头是否新高、梯队是否完整、量能是否异常
4. 切换预警：是否出现「新方向连续第 2 日全面强于旧主线」
5. 一句话操作提示（对照当前环境态）

纪律：单日数据只更新状态，不推翻周度主线结论；若出现主线级别的新爆发（板块 ≥20 只涨停 + 出现龙头 + 明确产业/政策催化），标注「新候选，待周度四维检验」。
```

## 五、人工复核检查单（判断 AI 输出质量）

| # | 检查项 | 合格标准 |
|---|---|---|
| 1 | 数据真实性抽查 | 任选 3 个数字对照行情软件，误差合理、来源日期齐全 |
| 2 | 结论-证据一致性 | 结论里的每个方向都能在 JSON 的 candidates / evidence 中找到对应证据 |
| 3 | 窗口纪律 | 报告结论引用的是 20-60 日窗口证据，而非单日涨跌幅 |
| 4 | 情绪数据核对 | 涨停家数/连板高度与开盘啦或同花顺人工对一次（AI 最易错项） |
| 5 | 「无主线」勇气 | 弱市中 AI 是否敢于给出「轮动市、无主线」结论 |

## 六、局限与注意

- AI 联网取数的实时性与准确性无法完全保证，**涨停/连板等情绪数据是最易出错的部分**，人工抽查（检查单第 4 项）不可省；
- 东方财富与同花顺的概念板块分类存在口径差异，跨来源对比时以同一来源为准；
- 环境态广度阈值（35% / 55%）、20 日涨幅 50% 等参数为**经验参数**（与主报告三态表口径一致），可依个人复盘样本微调，每次只调一个并记录；
- 主线判断本质是概率游戏：模板的价值在于强制证据结构化、防止单日冲动，而不能消除不确定性；
- 建议按周度节奏使用完整版，**高频跑完整版反而会放大噪音、诱发过度交易**——日度交给轻量版；
- AI 输出的 JSON 字段不全时，报告页会对缺失项显示「数据缺口」并整体降级呈现——这是设计内行为，勿因页面留白而质疑模板；
- relativeStrength 逐日序列多数情况只能取到区间快照，序列不足 4 点时报告页的相对强度图自动降级为占位说明，不影响其余板块渲染。
