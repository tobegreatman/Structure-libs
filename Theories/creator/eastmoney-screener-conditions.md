## 使用说明

东财选股器有两种用法，本文都给出：

1. **手动条件组合**：在「条件选股」页逐项添加条件（条件项名称以页面实际显示为准，不同版本可能略有差异，找不到完全一致的条件时用近义条件替代）；
2. **语句选股（推荐）**：选股器支持在搜索框直接输入自然语言条件语句，自动生成条件——每个信号附一条可直接复制粘贴的完整语句。

**共性前置条件（两个信号都要加）**：先排除不具备交易性的标的，再谈信号。

| 条件项 | 设置值 | 目的 |
|---|---|---|
| ST 状态 | 非 ST、非 *ST、非退市整理 | 排除问题股 |
| 交易状态 | 正常交易（排除停牌） | 保证可买可卖 |
| 上市天数 | > 250 天 | 次新股波动结构不同，不适用本体系 |
| 流通市值 | > 50 亿 | 保证流动性，避免小盘流动性陷阱 |
| 股价位置 | 收盘价 > 60 日均线 | 趋势过滤的底线（两个信号共用） |
| 均线关系 | 20 日均线 > 60 日均线 | 上升趋势成立（趋势过滤三条件之二） |
| 距 60 日低点涨幅 | < 80% | **A 股强化**：排除高位接力——自 60 日低点累计涨幅 >80% 后的突破是情绪流地盘，趋势流不碰 |

## 信号 A · 平台突破（放量突破关键平台 / 前高）

> A 股定位：**打折信号**——T+1 当日买错无法纠错、假突破比例高，必须「三重锁」（进攻态 + 放量 + 板块共振）全闭才允许执行（规则 9.3）。

### 手动条件组合

| # | 条件项 | 设置值 | 对应条款 |
|---|---|---|---|
| 1 | 共性前置条件（见上表 7 项） | — | 能力圈 / 趋势过滤 / 高位回避 |
| 2 | 近 20 日区间振幅 | < 15% | ① 平台整理 ≥ 20 个交易日（箱体越窄越标准；强势股可放宽到 20%） |
| 3 | 今日涨跌幅 | ≥ +2% | ③ 收盘站上平台上沿 2% 以上（以突破日力度近似） |
| 4 | 创 N 日新高 | 创 20 日新高（收盘价口径） | ③ 突破平台上沿 / 前高 |
| 5 | 量比 | ≥ 2 | ② 放量（量比 = 当日量 ÷ 过去 5 日均量，是对「≥ 20 日均量 1.8 倍」的最近似内置条件） |
| 6 | 换手率 | ≥ 3% 且 ≤ 15% | ② 辅助确认真实参与；>15% 警惕情绪极点 |
| 7 | 连续涨停天数 | 0（今日非一字板、非连板） | **A 股强化**：不接连续一字涨停后的开板（禁做清单⑫） |

### 语句选股（可直接粘贴）

```
非ST；非停牌；上市天数大于250天；流通市值大于50亿；收盘价大于60日均线；20日均线大于60日均线；现价距离60日最低价涨幅小于80%；最近20日区间振幅小于15%；今日涨幅大于2%；收盘价创20日新高；量比大于2；换手率大于3%小于15%；非涨停；非连续涨停
```

### 机器筛不出、必须人工复核的条款

- ❌ **三重锁第三锁「板块共振」（规则 9.3）**：选股器按个股筛选，无法判断板块——筛出后必须人工核对：所属板块指数当日是否同步上涨、板块内是否有 ≥ 3 只个股同步走强。**缺共振 → 降为试错仓（正常仓位一半）**；
- ❌ **平台形态质量**：20 日振幅 < 15% 只是「窄幅」的近似，是否构成规则箱体、上沿是否清晰，必须看图确认；
- ❌ **尾盘偷袭排除**：14:30 后直线拉升的突破放弃（看当日分时）；且 T+1 下不做 14:30 后的追高买入（禁做清单⑪）；
- ❌ **长上影排除**：突破日上影线 > 实体 2 倍放弃（看当日 K 线）；
- ❌ **高位回避复核**：「距 60 日低点 <80%」已入机筛条件，但仍需目测——处于历史大顶区域、筹码密集套牢区下方的突破，即使满足数值条件也降级处理；
- ❌ **环境态（三重锁第一锁）**：信号 A 只在**进攻态**执行——周日已更新的环境态为进攻，才可进入十问清单。

## 信号 B · 缩量回踩（上升趋势中的缩量回踩 20 日线）

> A 股定位：**主力信号**——A 股短期反转效应显著强于动量（中文实证一致结论），「买在回调处」天然胜率更高、止损更近；中性态下体系只保留本信号。

### 手动条件组合

| # | 条件项 | 设置值 | 对应条款 |
|---|---|---|---|
| 1 | 共性前置条件（见上表 7 项） | — | ① 上升趋势 + 高位回避 |
| 2 | 60 日均线方向 | 向上（今日 MA60 > 5 日前 MA60） | ① 趋势质量的加强项 |
| 3 | 距 60 日最高价 | 收盘价距 60 日最高价 < 15% | ① 强势股不深度回调（趋势过滤三条件之三） |
| 4 | 与 20 日均线距离 | 收盘价在 20 日均线的 ±3% 以内 | ② 回踩至 20 日线附近 |
| 5 | 量比 | ≤ 0.7 | ③ 缩量（对「< 20 日均量 70%」的最近似内置条件） |
| 6 | 今日涨跌幅 | -3% ~ +1% | ③ 回踩日应是小实体，大跌或大涨都不是标准回踩 |
| 7 | K 线形态 | 十字星 / 长下影线（若条件库中有此项，二选一作为可选条件） | ④ 止跌 K 线的机器近似（可选，宁缺毋滥） |

### 语句选股（v2.2 终版 · 可直接粘贴）

> 2026-10-09 两次修正：第一版含「正负 3%」「大于-3%」等表述解析不稳；「距离 / 比值」表述实测在回测引擎失败。**最终统一改用乖离率 BIAS（指标原生条件，已实测 ✅）**：BIAS20 ∈ [-3,3] 即「距 20 日线 ±3%」；BIAS60 < 15 近似「未深度回调」的强势过滤。高位回避（距 60 日低点 <80%）引擎表达不可靠，移出语句改人工复核。

```
非ST；正常交易；上市天数大于250天；流通市值大于50亿；收盘价大于60日均线；20日均线大于60日均线；今日60日均线大于10日前60日均线；60日乖离率小于15；20日乖离率介于-3到3之间；今日成交量小于5日平均成交量的0.8倍；今日涨跌幅小于1%；今日跌幅小于3%
```

修正点对照（三版演进）：

| v1 原版 | 问题 | v2.2 终版（实测驱动） |
|---|---|---|
| 收盘价距离20日均线**在正负3%以内** | 「正负」「距离」「比值」全部解析失败 | **20日乖离率介于-3到3之间** ✅ |
| 收盘价距离60日最高价小于15% | 同上 | **60日乖离率小于15**（近似：相对 60 日线偏离不大 = 未深度回调） |
| 今日涨跌幅**大于-3%**小于1% | 负号是经典翻车点 | 拆两条：涨跌幅<1% + **跌幅**<3% |
| 现价距离60日最低价涨幅小于80% | 复合表述解析失败 | **移出语句**，人工目测高位回避 |
| 60日均线向上 | 「向上」是模糊词 | 今日60日均线**大于10日前**60日均线 |
| 非停牌 | 部分版本不识别 | 正常交易 |
| 量比小于0.7 | 过严 + 量比支持度存疑 | **成交量<5日平均成交量的0.8倍**（初筛放宽，复核再卡 0.7） |

### 筛不出结果时的三级漏斗调试法

结果为 0 时不要直接放弃，按漏斗逐级验证，定位是「解析问题」还是「市场状态问题」：

**第 1 级 · 基础趋势池**（验证语句引擎是否工作）
```
非ST；正常交易；上市天数大于250天；流通市值大于50亿；收盘价大于60日均线；20日均线大于60日均线
```
预期：正常市况出 300-800 只。**若这一级就为 0** → 语句解析问题，逐条核对生成的条件（看哪条被误解析），改用手动模式添加。

**第 2 级 · 加位置条件**（验证回踩定位）
```
……（第1级全部）；60日乖离率小于15；20日乖离率介于-3到3之间
```
预期：几十只。若从几百只直接归零 → 乖离率条件解析失败，改用自然语言「股价回踩20日均线」或手动模式添加 BIAS 指标条件。

**第 3 级 · 加缩量与小实体**（完整信号）
```
……（第2级全部）；今日成交量小于5日平均成交量的0.8倍；今日涨跌幅小于1%；今日跌幅小于3%
```
预期：**0-15 只都属正常**。回踩信号本就稀少——如果第 2 级有几十只而第 3 级为 0，说明当天没有缩量回踩标的，**这就是体系的「宁缺毋滥」在正常工作，当天不开新仓即可**。

**放宽档（连续多日第 3 级为 0 时可选）**：成交量放宽到 0.9 倍、BIAS20 放宽到 -4~4、BIAS60 放宽到 20。每次只放宽一项并记录——放宽的本质是降低信号质量换数量，仓位应同步保守。

### 机器筛不出、必须人工复核的条款

- ❌ **高位回避（原机筛条件已移出）**：目测个股是否自 60 日低点累计涨幅 >80% 或处于历史大顶区域——是则放弃或降级；
- ❌ **缩量质量复核**：量比 ≤0.8 只是初筛口径，标准信号要求 <0.7，且需目测近 3-5 日成交量柱是否持续地量；
- ❌ **止跌 K 线确认**：下影线 / 阳包阴 / 缩量十字星必须看图确认，且**次日不创新低才入场**——筛出日 ≠ 买入日；
- ❌ **回踩过程整体缩量**：量比只反映当日，回踩段（近 3-5 日）是否持续地量需目测成交量柱；
- ❌ **回踩不破位**：跌破 20 日线后 3 日内收不回的放弃（看 K 线结构）；
- ❌ **板块同步性**：板块同步走弱时，个股回踩失败率高（看板块指数）；
- ❌ **环境态**：进攻态 / 中性态均可执行信号 B；**防守态停用**。

## 周线变体（规则 9.4 · 无法盯盘者推荐）

A 股日线噪音大、假信号多。无法盯盘的投资者把整套信号上移一档：周线假信号更少、频率降至每月数笔，反而适合业余执行。**止损距离变宽时仓位公式（风险预算 ÷ 止损距离）会自动缩小仓位，无需额外规则。**

手动模式：把条件周期从「日线」切换为「周线」后套用下表；语句模式直接粘贴下方语句。

### 周线信号 A · 平台突破（平台 ≥ 20 周）

```
非ST；非停牌；上市天数大于250天；流通市值大于50亿；周线收盘价大于30周均线；最近20周区间振幅小于25%；本周收盘价创20周新高；本周成交量大于20周均量的1.8倍
```

### 周线信号 B · 回踩 10 周线

```
非ST；正常交易；上市天数大于250天；流通市值大于50亿；周线收盘价大于30周均线；10周均线大于30周均线；10周乖离率介于-3到3之间；本周成交量小于20周均量的0.8倍
```

（高位回避同日线版：移出语句，人工目测是否自 60 日低点涨幅 >80%。若「10周乖离率」解析失败，把条件周期切为周线后手动添加 BIAS 指标条件，参数设 10。）

### 周线版人工复核要点

- 止损锚同步上移：信号 A 用平台周线低点，信号 B 用回踩周低点或 30 周线（取较近者）；
- 周线信号以**周五收盘**确认，周五尾盘或下周一开盘执行，不在周中抢跑；
- 环境态、板块共振、主线过滤的检查口径不变（仍看日线级别的大盘与板块）。

## 回测系统（Huice）排错：5 年零结果的二分定位法

> 2026-10-09 增补。症状：信号 B 语句在回测系统（https://xuangu.eastmoney.com/Huice）跑 5 年维度仍零结果。
> 结论先行：**5 年零结果 ≠ 信号不存在，而是条件被回测引擎误解析成不可能成立的组合**。回测引擎支持的条件子集比选股器更窄，「距离」「正负」「量比」类表述最容易静默失效。

### 第一步：单条件逐个跑（找出致死条件）

在回测页**每次只放一条**（前置「非ST；上市天数大于250天」可保留），记录每条的结果数：

| 顺序 | 单测语句 | 预期（5 年维度） | 若结果为 0 |
|---|---|---|---|
| 1 | 收盘价大于60日均线 | 大量 | 回测引擎本身异常，换浏览器/时段重试 |
| 2 | 20日均线大于60日均线 | 大量 | 引擎不支持均线比较，此路不通 |
| 3 | 今日60日均线大于10日前60日均线 | 大量 | 改为「60日均线呈上升趋势」或删去 |
| 4 | 收盘价距离60日最高价小于15% | 较多 | **高危项**：改比值法（见下） |
| 5 | 收盘价距离20日均线3%以内 | 较多 | **最高危项**：改比值法（见下） |
| 6 | 量比小于0.8 | 较多 | 引擎可能不支持量比，改成交量倍数法 |
| 7 | 今日涨跌幅小于1%；今日跌幅小于3% | 大量 | 涨跌幅表述问题，拆单条再测 |

哪一条单测为 0，就把它换成下方的「回测友好表述」；全部单测正常后，再两条、三条逐步合并——**合并到哪一步归零，问题就出在新加的那条与已有条件的交互上**。

### 第二步：回测友好表述（指标法替代「距离 / 比值」表述）

> 2026-10-09 实测更新：「收盘价与20日均线的比值大于0.97小于1.03」在回测引擎中**同样解析失败**（比值表述不被支持）。最终解：用**乖离率 BIAS**——BIAS20 =（收盘价−20日均线）÷20日均线×100，±3% 即 BIAS20 ∈ [-3, +3]。指标类条件是回测引擎的原生能力，识别率最高。

「距离 X 均线/高点 N%」类条件的替代优先级（逐级试，通过即停）：

| 级别 | 表述 | 说明 |
|---|---|---|
| ① 首选 | 20日乖离率介于-3到3之间 | 一条表达 ±3%，指标原生条件 |
| ② 拆条 | 20日乖离率小于3；20日乖离率大于-3 | ① 失败时拆两条试（注意负号仍是风险点） |
| ③ 自然语言 | 股价回踩20日均线 / 收盘价接近20日均线 | ② 也失败时用模糊语义，引擎内置映射 |
| ④ 兜底 | **删去该条件** | 回测只跑「趋势+缩量」子集，回踩位置改人工看图或本地回测补——宁可少一个条件，不要一个假条件 |

其余条件的替代：

| 原表述 | 回测友好替代 |
|---|---|
| 收盘价距离60日最高价小于15% | 若「距离」解析失败：60日乖离率小于15（粗近似，含义变为距60日线而非最高价）；或删去改人工 |
| 量比小于0.8 | 今日成交量小于5日平均成交量的0.8倍（仍失败则删去，缩量改人工复核） |
| 60日均线向上 | 今日60日均线大于10日前的60日均线 |

### 第三步：回测版信号 B 完整语句（指标法版）

```
非ST；上市天数大于250天；流通市值大于50亿；收盘价大于60日均线；20日均线大于60日均线；今日60日均线大于10日前的60日均线；20日乖离率介于-3到3之间；今日成交量小于5日平均成交量的0.8倍
```

（「距60日最高价<15%」与当日涨跌幅条件已拿掉：前者用乖离率近似含义会变，后者对回测无意义——回测看的是信号出现后 N 日表现，少一条少一个翻车点。回踩位置若①-③全部失败，按④兜底删去，只回测「趋势+缩量」子集。）

### 已实测的回测引擎支持度（2026-10-09 持续更新）

| 表述 | 支持情况 |
|---|---|
| 收盘价大于60日均线 / 20日均线大于60日均线 | ✅ 均线比较可用 |
| 收盘价距离20日均线3%以内 | ❌ 「距离」表述回测引擎解析失败 |
| 收盘价与20日均线的比值大于0.97小于1.03 | ❌ 比值表述同样不支持 |
| 20日乖离率介于-3到3之间 | ✅ 实测可用（2026-10-09 用户验证） |

### 回测通路已通：信号 B 参数扫描方案

语句跑通后，按下面的网格逐组改参数回测（每次只改一个参数），把结果填入记录表——这就是体系缺的那块真实数据：

**基准语句**（每次替换 `{ }` 内的参数值）：

## 局限与注意

- 东财内置「量比」对比的是 5 日均量，与信号定义中的 20 日均量存在口径差异——属于近似替代，偏严（放量时）/ 偏松（缩量时），人工复核成交量柱是必要补充；
- 「近 20 日区间振幅」「距 60 日最高/最低价」等条件在不同版本的选股器中名称可能略有出入，手动模式找不到时用语句模式表达；
- **选股器无法表达「板块共振 / 主线 / 催化 / 环境态」**——三重锁机器只能锁一道半（放量 + 半个趋势），其余永远靠人工；这正是规则 9.3 要求人工降仓/放弃的原因；
- 语句选股对「非连续涨停」「距离 60 日最低价涨幅」等表述的解析可能因引擎版本而异，粘贴后请逐条核对生成的条件是否与预期一致，解析失败的条件改用手动模式添加；
- 条件中的阈值（振幅 15%/25%、量比 2、±3%、80% 等）与报告正文一致，属经验参数，可按自己的样本复盘结果微调，但每次只改一个并记录。
