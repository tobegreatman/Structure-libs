01

认知筑基：六条第一性原理

所有技术方法都建立在这六条之上。行情越极端，越要回到这里。

原理一
买股票 = 买公司
你买的不是一串跳动的代码，而是企业未来现金流的索取权。代码背后没有生意，就只有博弈。
原理二
价格 ≠ 价值
市场短期是投票机（情绪与资金），长期是称重机（盈利与现金流）。赚短期的钱靠判断情绪，赚长期的钱靠判断生意。
原理三
安全边际
好公司 + 好价格缺一不可。再好的资产，买贵了也可能让你三年不赚钱。预留犯错空间，是对自己无知的诚实。
原理四
能力圈
只投看得懂的行业和公司。圈的大小不重要，知道圈的边界在哪里才重要。看不懂的上涨，通常以看不懂的下跌收场。
原理五
预期差 = 超额收益
股价反映的是市场共识。你赚的钱来自"共识与现实的差"：被低估的盈利弹性、被高估的短期风险、被忽视的新业务。没有预期差，就没有超额收益。
原理六
概率与赔率
市场没有确定性，只有期望值。单笔对错不重要，长期反复执行"高期望值"的动作才重要。用仓位管理概率，用止损保护赔率。

A 股五个结构性特征（与成熟市场的关键差异）

特征含义与应对
T+1 交易制度当日买入次日才能卖出，日内犯错无法当场纠正 → 买点要求更高，情绪化追高的代价被制度放大。
涨跌停限制主板 ±10%，创业板 / 科创板 ±20%，ST ±5%。涨停买不进、跌停卖不出 → 流动性风险真实存在，不碰连续缩量涨停后的高位接力。

散户占比高、波动大情绪与题材轮动快、波动率高 → 止损纪律和仓位管理的权重，比成熟市场更高。
颜色约定相反红色 = 上涨，绿色 = 下跌，与欧美市场相反 → 看境外行情软件时注意切换直觉。
02

判断市场：先定档位，再谈个股

同一支股票，在不同的市场档位里完全是两笔交易。仓位天花板由市场状态决定，不由你的信心决定。

市场四档状态

档位特征操作含义
进攻档指数上行 + 广度健康 + 主线清晰 + 量能配合可加风险敞口，聚焦主线龙头，仓位可至上限
震荡档指数横盘、热点快速轮动、赚钱效应一般精选个股、控制总仓位、做短不做长
切换档旧主线退潮、新主线未明、结构混乱减少新进场，等结构清晰再动手
防守档广度恶化、防御板块走强、量能萎缩减仓 + 防守配置 + 现金为王

广度比指数更诚实——五个体检指标

  • 涨跌家数比：指数涨但下跌家数更多 = 少数权重硬拉，典型脆弱信号。
  • 创新高 / 新低个股数：新高持续扩容是健康牛；新高萎缩是动能衰竭。
  • 行业参与度：80% 以上行业上涨为全面扩散（健康）；少数赛道独涨为局部抱团（高风险）。
  • 成交额：价涨量增可信；价涨量缩是存量博弈的互掏口袋。
  • 北向资金 / 两融余额：观察增量资金的方向与持续性，而非单日进出。
核心警示：广度恶化通常先于指数回落。指数还在涨、广度已掉头，往往是聚焦过度后的脆弱阶段。"指数没跌"绝不等于"市场健康"。
03

精选个股：深度研究七步法

研究不是资料堆砌，而是回答两个问题：市场为什么买这只股票？未来还会不会继续买？

  1. 拆解业务结构：哪块业务最关键、哪块决定估值、是否有真壁垒。区分主业 / 增长业务 / 衰退边缘业务。
  2. 行业格局与公司位置：行业处于导入 / 成长 / 成熟 / 下行哪一阶段？空间多大？公司是龙头、细分龙头、追赶者还是边缘？
  3. 核心投资逻辑（2-4 条）：每条必须写清——逻辑本身、为什么成立、对业绩或估值的影响路径、是否已被充分定价。拒绝"受益于行业发展"这类泛逻辑。
  4. 未来 1-3 年增长驱动：来自产品放量、价格上行、份额提升、新业务还是成本改善？明确最关键的那一个业绩变量。
  5. 市场共识与预期差：市场已普遍接受什么？真正可能形成超额收益的预期差是什么？这是高质量投研的核心交付。
  6. 估值方法选择与位置：选什么方法、为什么（见模块 04），当前处于历史分位什么位置、行业横向对比如何。
  7. 风险清单：短期与中期分开（需求 / 价格 / 客户集中 / 产能 / 政策 / 竞争），不泛泛提示。
一句话本质检验："买这家公司，本质上是在买 ______。"（如"买的是 AI 算力资本开支周期的量价齐升"）——逼自己把逻辑收敛成一句可证伪的话。

长周期视角

财务与估值数据优先看近 10 年：3 年看不出周期位置和估值中枢；上市不足 10 年的次新股按实际年限评估。所有关键数据必须可追溯到来源与时点，多源冲突时优先采信交易所公告、公司年报等一手来源。

04

估值定价：先分类，再选尺

估值回答三件事：该用什么方法、当前股价里已经包含了什么、什么会触发重估或杀估值。

公司类型 × 估值方法对照

公司类型首选方法关键注意
高成长PE / PEG / PS / EV-EBITDAPEG 看增速与估值的匹配，增速证伪即双杀
稳健成长PE / PEG看增长持续性而非单年增速
周期PB / 周期中枢 PE / 盈利拐点高 PE 时可能是底部（盈利最差），低 PE 时可能是顶部
价值 / 红利PE / PB / 股息率验证分红持续性，不能只看单次股息率
平台 / 金融分部估值 / DCF / P-AUM多业务加总，避免一把尺子量全身

估值位置：历史分位三档

  • 30% 分位以下：偏低——但低估值不等于便宜，先排除基本面恶化的"价值陷阱"。
  • 30%-70%：中性——赚业绩的钱，估值贡献有限。
  • 70% 以上：偏高——高估值不等于必须卖，但要求增速与质量持续兑现。

拆解"股价里已经包含了什么"

高估值隐含：未来高增速、景气持续、市占率提升、新业务高弹性。低估值隐含：周期下行担忧、业绩见顶、治理折价。说清楚市场已定价了什么，估值分析才有意义。

重估触发
业绩超预期 · 产业趋势强化 · 商业模式改善 · 资金风格切换 · 治理改善
杀估值触发
增速下修 · 景气拐点 · 竞争恶化 · 风险偏好下降 · 政策冲击

DCF 使用纪律（如需）

WACC 通常取 8%-12%，永续增长率 2%-3%；必须做 Bear / Base / Bull 三情景，不把单一情景当目标价；终值占比超过 70% 要警惕模型失真。跨公司对比前先核对财年口径（财年 ≠ 自然年）。

05

交易计划：具体条件 + 具体动作

"逢低布局、注意风险"不是计划。计划 = 现在处于什么位置 → 什么条件做什么动作 → 什么情况计划作废。

第一步：判断当前交易位置

位置特征信号
低位启动长期下跌后横盘 / 放量突破30 日低点 + 放量
趋势中继上升趋势中回调5 日线附近 + 缩量
高位加速连续大涨后加速远离 5 日线 + 放量（警惕透支）
高位震荡高位横盘5 日线走平 + 高换手
下跌反抽下跌后反弹5 日线下方 + 无量（持续性弱）

第二步：入场四依据（缺一不可，理由不足宁可等确认）

  • 逻辑催化：政策 / 业绩 / 订单，有明确的事件或数据支撑。
  • 趋势结构：突破 / 回踩 / 反转，位置对。
  • 量价配合：放量上涨、缩量回调为健康结构。
  • 市场环境：大盘与板块支持（回到模块 02 定档）。环境不支持时降仓或放弃。

第三步：分仓路径（一把梭不是计划）

批次比例触发条件
试错仓10-20%首次信号出现
确认仓+20-30%走势符合预期
加仓仓+20-30%强势确认 / 关键突破
重仓>70%仅限极强势 + 市场环境支持

第四步：止盈与失效条件

  • 止盈三种：目标止盈（前高 / 阻力位）、情绪止盈（换手 >15% + 放量滞涨）、时间止盈（计划周期到）。分批执行：先回收成本，再吃主升，留底仓博第二段。
  • 失效条件（高质量计划必备）：催化证伪 / 板块转弱 / 龙头负反馈 / 放量破位 / 次日反馈差。任何一条触发，计划作废而非修改。
止损位写完就是写完，不要事后宽松；环境不支持时，敢直说"这笔不执行"。
06

仓位风控：由风险反推，不由信心正推

仓位是风险决策，不是方向决策。信心高 ≠ 应该重仓；没有止损位，就没有仓位计算。

核心公式

可承受仓位 = 单笔风险预算 ÷ 止损距离
例：账户 100 万，单笔最多亏 1%（1 万），止损距离 7% → 仓位 ≈ 14.3 万
  • 先定风险边界：单笔最大可承受亏损（常见 0.5%-2% 账户）、整体仓位天花板、行业 / 风格集中度上限。
  • 不确定性决定首笔：不确定性越高，首笔越克制（10-20% 试错仓起步），验证后再放大。
  • 止损距离过远 → 缩小仓位，而不是放宽纪律。止损距离是仓位的分母。
  • 组合相关性是隐藏风险：3 只半导体加在一起，就是一笔半导体仓位。新仓按"补充暴露"而非独立头寸处理。
  • 加仓条件：原逻辑被强化 + 走势符合预期 + 量价配合 + 环境升级。不在浮盈上盲目加码。
  • 压力测试：想象开盘跳空、连续不利波动、环境突变——不能接受，说明当前仓位偏大。

07

止损纪律：价格 × 逻辑 × 时间，三维刹车

止损的本质不是认错，而是用确定的小成本，消除不确定性的大风险。

价格止损
客观位 + 确认方式
跌破关键支撑（前低 / 5 日线 / 20 日线）或幅度 -5% 至 -8%（按波动率调整）。必须写清确认方式——收盘破位、盘中破位还是连续破位，避免被瞬时插针误伤。
逻辑止损
买入理由消失
核心催化失效（利好落空 / 公告澄清）、板块转弱（龙头跌停 / 板块跌超 5%）、放量破位（成交量放大 1.5 倍 + 跌破关键位）。逻辑没了，价格没跌也该走。
时间止损
资金的机会成本
预期多久验证？短线 5-10 个交易日、中线 1-2 个月仍横盘弱势，资金占用已达时间阈值 → 降仓或退出，把资金还给更好的机会。

触发后的动作顺序（纪律的核心）

  1. 触发即执行事先写好的动作：先减半再观察、一次性退出、或等收盘确认——触发前定好，触发后照做。
  2. 触发后禁止重新评估持有理由——评估应在触发前完成。"再等等说不定回来"是自我合理化。
  3. 区分噪音与真失效：盘中快速插针后收回通常是诱空；连续多日趋势性破位才是真失效。
  4. 目标价到达 ≠ 必须卖：判断预期兑现度与新催化，强势穿越可上调目标；但目标价触发后回落，重点警惕兑现风险。
脱锚训练：成本价不是市场关心的变量。"我成本 35 元套了 40% 怎么办" → 换成"以现在的基本面、估值、位置，它今天还值不值得持有？"市场从不知道你的成本。
08

复盘进化：区分运气与能力

没有复盘的体系会退化。复盘的目标只有一个：让下一次决策的期望值更高。

交易日志四要素

要素记录内容
买入理由当时的投资逻辑 + 预期差 + 一句话本质（买它本质上是买什么）
当时预期预期多久验证、目标位、止损位、失效条件——全部事前写死
实际结果盈亏、持有时长、过程最大回撤
偏差归因结果与预期的差来自哪里：判断错误 / 执行走样 / 随机波动？
  • 赚钱 ≠ 做对：靠运气赚的钱，复盘时要标记为运气，否则会强化错误动作。
  • 亏钱 ≠ 做错：按系统执行的止损是成本，不是错误；该止没止才是错误。
  • 维护一份个人错误清单：追高、一把梭、止损走样、盈利不走坐过山车——重复犯同一个错之前，先把它写下来。
  • 拉长周期看自己：单季盈亏无意义，以 3-5 年年化收益与最大回撤评价体系是否有效。
  • 让结论回流：复盘发现的环境误判 → 修正模块 02 的档位标准；发现的逻辑错误 → 修正模块 03 的研究清单。
