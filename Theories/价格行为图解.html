价格行为
读懂市场的语言

不依赖任何指标，仅凭 K 线轨迹本身研判多空博弈。本指南精炼价格行为理论的完整体系——从市场结构、K线形态，到流动性、订单块与交易方法论。

“K线是单词，位置才是句子。” — 价格行为第一定律

01 · 核心哲学

价格，是唯一的真相

所有技术指标都是价格的数学衍生品——滞后且失真。价格行为（Price Action）直接研究价格轨迹本身：K线是订单流留下的足迹，每一根影线、每一个高低点，都是买卖双方真金白银投票的结果。

01 核心命题

价格包含一切

消息、情绪、资金最终都凝结为成交价。与其猜测"为什么涨"，不如研究"涨的方式"——急涨缓涨、放量缩量、突破失败，这些行为细节才是可交易的信号。

02 市场本质

订单流驱动

价格由三类订单推动：限价单（高抛低吸）、止损单（追涨杀跌）、市价单（恐慌与贪婪）。趋势市场是止损单的市场，区间市场是限价单的市场。

03 统计现实

70–80% 时间在震荡

Al Brooks 的著名论断：市场大部分时间处于区间，约 80% 的突破尝试会失败并回归区间（均值回归）。这决定了做回调比追突破的期望值更高。

状态一

趋势 Trending

高低点持续抬升或降低，止损单驱动，回调即燃料。特征：K线实体大、影线短、同色连续。

状态二

区间 Ranging

水平高低点反复震荡，限价单驱动，均值回归主导。特征：K线重叠多、上下影线长、十字星频现。

状态三

突破 Breakout

区间边界被有效穿越，动能切换。注意：突破失败本身是高概率的反向信号（假突破交易法）。

为什么有效
价格行为有效的根基是市场微观结构的自我实现：全球数百万交易者盯着相同的高低点、整数关口、前高前低挂单与设止损——这些共识位置成为真实的订单聚集区，价格到达时必然产生物理性的供需失衡。价格行为不是玄学，是订单流的可视化。
02 · 市场结构

结构，是价格的骨架

市场结构（Market Structure）把杂乱的波动抽象为摆动高低点的序列，是所有价格行为分析的起点。看懂结构，才知道自己身处趋势的哪个阶段、反转的哪个环节。

上升趋势定义

HH 与 HL 交替

只要价格持续制造"更高的高点和更高的低点"，多头结构完好。任何一个 HL 被收盘跌破，都要立即警觉——那可能就是性质转变的第一枪。

下降趋势定义

LH 与 LL 交替

持续制造"更低的高点和更低的低点"。空头结构中只做回调做空，直到出现有效的结构反转信号。

延续信号

BOS Break of Structure

顺势突破最近一个已确认摆动极值（升势收盘破前高 / 跌势收盘破前低），确认趋势延续。三条铁律：① 必须实体收盘越位，影线刺穿不算；② 必须是结构级摆动点，内部小波动无效；③ 突破后需出现同向新结构（如升势中形成新的 HL）确认，否则可能只是流动性收集。

反转预警

CHoCH Change of Character

首次逆势破位（升势中收盘跌破最近 HL；跌势中收盘升破最近 LH），是趋势可能反转的最早结构预警。与 BOS 的关键区别：BOS 顺势 = 延续确认；CHoCH 逆势 = 预警但不保证反转（可能只是深回调或诱多/诱空）。典型序列：CHoCH → 形成反向摆动 → 反向 BOS，新趋势才算确立。

03 · 支撑与阻力

记忆与订单浇筑的边界

支撑 / 阻力（S/R）不是一堵"墙"，而是过去供需失衡留下的情绪记忆区。价格与它只有三种互动：测试、突破失败、成功突破。

形成机制

为什么会"支撑"

支撑下方聚集着：获利多头的限价买回 + 踏空者"回到 X 就买"的委托 + 早期空头的获利了结单。记忆效应：曾造成盈亏的价位会被记住并再次挂单，形成自我实现。整数关口天然吸单（00 / 50 关口）。

强位四要素

怎么判断强度

① 触碰次数越多越显著；② 时间跨度越大越强（周线位 > 5分钟位）；③ 离开速度越快越有说服力；④ 突破时放量。注意：这是经典 S/R 逻辑——与供需区"越测越弱"恰好相反，两者机制不同，并不矛盾。

画法细节

是区域，不是线

以影线簇画边界而非收盘价；周期越高区域越宽。趋势线连 2 点起、≥3 触点更有效；不可大量切过 K 线实体，过陡的线难以维持。通道 = 趋势线平移至对侧。

假突破

影线 vs 实体

实体收盘越位 = 真突破；仅影线刺穿后收回 = 扫荡 / 假突破。明显高低点、等高等低点、前日高低点、趋势线沿线——都是止损簇聚集地，机构推价穿位触发止损、以其为对手盘成交后反抽。

Brooks 视角

趋势线即流动性

Al Brooks：第一次趋势线突破通常失败——假突破本身是最可靠的顺势信号。微观通道（2–10 根无回调K线）的第一次反向突破"几乎肯定失败"。过冲的触点（climax）反而是反转证据。

04 · K线语言

每根K线，都是一场战役记录

K线形态的价值 = 形态本身 × 所处位置。同一根锤子线，出现在趋势末端的关键支撑是黄金信号，出现在区间中部则是随机噪音。先看位置，再看形态。

信号之王

Pin Bar 锤子线 / 流星线

构成要件（严格）：① 影线 ≥ 实体 2 倍（占整根K线 2/3，理想 3/4）；② 影线必须突破前期价格结构——"皮诺曹的鼻子"要伸出去；③ 实体位于 K 线另一端；④ 收盘收回母线（前一根）开盘价附近。

心理机制：长下影 = 空头全力下压后，买盘将跌幅全数收复——卖方最后的进攻失败、低位承接者反扑；长上影 = 追多者在高位被套、供给出现。影线突破结构越深，拒绝信号越强。

单根家族

Marubozu 与 Doji

Marubozu（光头光脚）：无影线，开盘即最低、收盘即最高——一方全程碾压、零抵抗，多为突破 / 趋势延续的动能K线。

Doji（十字星）：开盘≈收盘，多空打成平手。出现在长期单边趋势末端 = 动能衰竭的警报；出现在区间中部 = 无意义噪音。变体：长腿十字（双向剧烈拉锯）、蜻蜓 / 墓碑。

位置 > 形态
同一个形态，在趋势末端 + 关键水平 + 整数关口出现才是 A+ 信号；半空"无人区"里的形态没有订单流支撑。Nial Fuller 的汇聚焦点（Confluence）：趋势 + 关键位 + 信号三者重叠，独立证据越多，概率越高。孤立形态 = 赌博。
05 · 图表形态

多空博弈的宏观剧本

图表形态是 K 线信号的放大版——用几十根K线讲述一个完整的供需转换故事。每个形态都有确认条件与量度目标，且记住：失败的形态本身也是信号。

06 · 供需区

机构订单的驻扎地

供需区（Supply & Demand Zone）假设：价格剧烈离开某个盘整区，是因为该区内残留着机构未成交完的挂单。价格回到这里，未成交订单继续成交，从而再次推动价格离开。

Base 构成

越窄越强

1–3 根（至多 5 根）小实体K线的紧密横盘。Base 越窄，机构订单越集中、越精准。

离开力度

Leg Out 铁律

离开K线必须是大实体、连续同向、突破前期结构的爆发式离开——出区力度证明区内失衡订单仍然存在。缓慢漂离形成的"区"无效。

新鲜度

首次回踩最优

机构未成交订单完整（例：10万股卖单只成交6万，剩4万仍挂在原价位）。每次回踩消耗订单，2–3 次显著测试后视为失效；被实体决定性穿过 = 订单耗尽，区作废。

维度经典支撑阻力供需区
识别依据反复测试的水平位（共识记忆）单次急剧离开的盘整（订单残留）
形态一条线 / 窄区域矩形区块（近端 = base 边缘，远端 = 形态极值）
强度演化测试越多越强测试越多越弱（订单被消耗）

07 · 流动性

止损单，是机构的猎物

现代价格行为的底层世界观：机构无法在单一价位吃满巨额仓位，散户止损单是最深、最可预测的流动性池——价格会先被"送往"那里，再走向真实方向。AMD 三段式：吸筹（Accumulation）→ 操纵（Manipulation）→ 分配（Distribution）。

BSL

买方流动性

堆积在旧高点上方：空头止损单（buy stop）+ 突破追买单。等高点（EQH）处订单密度最高——散户眼中的"明确阻力"，恰是磁铁。

SSL

卖方流动性

堆积在旧低点下方：多头止损单（sell stop）+ 突破追卖单。等低点（EQL）、前日低点、整数关口下方同理。

IDM

诱因 Inducement

主趋势内逆势的次级峰/谷，制造"趋势延续"假象诱散户进场，其止损被收割后成为真实方向的燃料。不交易 IDM，交易它之后。

机制说明（诚实的一课）
"机构故意猎杀止损"是解释性框架——它同样可能只是订单流自然的供需失衡，图表无法证实"意图"。但作为正期望的交易模式（扫荡 + CHoCH 确认），它在统计上长期有效：框架可以是隐喻，但概率必须是真实的。
08 · 订单块与公允价值缺口

机构足迹的精密坐标

订单块（Order Block）与公允价值缺口（Fair Value Gap）是 SMC / ICT 体系对供需区的精细化：把"区域"缩小到一根K线与一道缝隙，从而实现更紧的止损、更高的盈亏比。

订单块定义

Order Block OB

引发结构突破（BOS）的强冲动前最后一根反向K线：看涨 OB = 上涨突破前最后一根阴线（机构分批吸筹）；看跌 OB = 下跌突破前最后一根阳线（派发）。

有效性三要件：① 强冲动（≥3 根同向实体）；② 确实引发 BOS；③ 未被回测（fresh）。

机制：机构无法一次建满仓而不推动价格，故在反向K线内分批累积，剩余未成交挂单留存该区——回踩时继续成交 → 价格再次离开。

缺口定义

Fair Value Gap FVG

三根K线结构：看跌 FVG = K1 的下影线低点与 K3 的上影线高点之间的未重叠空隙（K2 大实体造成）；看涨方向镜像。

回补机制：急速行情使部分价位无人成交（单边成交 = 失衡 / 低效区），未成交订单仍挂在该区，市场倾向回归完成双边成交以修复失衡——FVG 同时是支撑阻力与磁铁。

失效演变

Breaker Block

OB 经流动性扫荡 + 实体突破后失效 → 极性翻转：原买方被套，回抽时保本离场 + 新方向进场者叠加，反应比普通 S/R 翻转更猛烈。

温和版本

Mitigation Block

无扫荡的失败推动后形成，机构用于回补旧仓，通常只反应一次，弱于 Breaker。两者都极性反转，强弱取决于形成原因。

缺口反转

IFVG 反转缺口

实体收盘完全穿过整个 FVG → 极性翻转（逻辑同 Breaker）；影线穿越 = 仍是测试（有效），部分穿越 = 消耗（移除）。OB 实体中点被收破是 OB 失效的早期预警。

09 · 多时间框架

自上而下：方向 · 位置 · 时机

逆着高周期趋势做低周期信号，等于给大资金当燃料——低周期信号本质上常是高周期行情的流动性。唯一例外：中周期出现真正的 CHoCH，预示高周期反转（此时也应减仓）。

HTF 高周期

D1 / W1 定方向

判定市场 bias（多头/空头/中性），标记关键 PD 阵列：未扫荡的流动性、未测试的供需区、主要结构位。只看不动。

MTF 中周期

H4 / H1 定位置

等价格进入 HTF 关键区。观察结构：该先被扫的流动性（IDM）扫了没有？扫描完毕 + 进入区域，才算"就位"。

LTF 低周期

M15 / M5 定时机

在关键区等待：扫荡 → 结构转变（CHoCH/MSS）→ 位移（displacement），在位移留下的 FVG / OB 处精确入场。扣动扳机的层级。

高层定方向 · 中层定位置 · 低层定时机
逆 HTF 趋势交易的胜率天然偏低：LTF 信号是 HTF 主导行情的燃料/流动性，长期统计期望为负。自上而下不是仪式感，是概率的数学。
10 · 交易方法论

从看懂，到执行

分析的产出不是观点，而是三样东西：入场价、止损价、目标价。三者构成盈亏比（R），R 与胜率的组合构成期望值——一切价格行为理论最终都服务于这个等式。

确认入场 Confirmation

  • 触及区域后，等 LTF 出现 CHoCH / 拒绝K线再进场
  • 胜率更高，代价是入场价更差
  • 可能错过不回踩的行情
  • 适合：弱区域、震荡市、初学者

激进入场 Aggressive

  • 直接在 OB / FVG / 区域中点挂限价单
  • 价格更优、盈亏比更高
  • 无确认，可能被直接穿透
  • 适合：新鲜区或 HTF 级别的强区域

盈亏平衡胜率 = 1 ÷ (1+R)。期望 = 胜率 × R − 败率 × 1。这意味着：与其提高胜率，不如提高 R、筛选 A+ 设置。

资金法则

单笔风险 1–2%

回撤的不对称性：−10% 需要 +11.1% 回本，−50% 需要 +100%。仓位由止损距离反推，每笔的美元风险恒定，而不是每笔的仓位恒定。

筛选纪律

A+ 设置清单

HTF 关键位 + 扫荡完成 + 结构转变 + 触发器——清单化打分，不满 4/5 就放弃。"眯眼测试"：需要费力论证才成立的机会，不是机会。

心理纪律

狙击手心态

90% 的时间等待，10% 的时间执行。报复性交易（试图"赢回来"）以日亏 1–2% 熔断切断回路。空仓的日子也是盈利的日子。

11 · 大师流派

四条路径，同一座山峰

价格行为理论的现代体系由几位标志性交易者奠基。他们视角各异，内核一致：价格优先、位置优先、概率优先。

裸K之王

Al Brooks 五部曲 · Bar by Bar

80% 法则：80% 的突破首次尝试失败、80% 的反转需要二次入场。趋势中只买回调——H2（两腿回调至 EMA）为最重要入场。二次入场：趋势线破位后立即出现同向强信号，证明原趋势仍控盘。目标用"磁铁"：前高前低、EMA20、测量移动。

流程化先驱

Lance Beggs YTC 价格行为

期望公式置于一切之前：胜率 × 均盈 − 败率 × 均亏，所有技术只改变其中一项。五步流程：HTF 环境 → S/R → 当前趋势 → 结构位置 → 锁定架构区。价格进入架构区后才看形态——位置永远优先于信号。强趋势中的逆势架构，是别人的陷阱；其失败即顺势入场。

简约主义

Nial Fuller Pin Bar · Fakey

只交易日图与周图的清晰信号：Pin Bar、Fakey（内包线 + 假突破收回）、内包线。形态的价值取决于位置——趋势中的关键位最准；逆势信号仅限日图 + 极清晰者。少即是多：每月数笔 A+ 交易，胜过每日数十笔平庸交易。

机构视角

ICT / SMC Inner Circle Trader

流动性驱动世界观：算法化地把价格送往流动性池（AMD：吸筹-操纵-分配），散户的支撑阻力是"目标"而非"屏障"——双顶不做空，先等上方扫荡。机构足迹 = 位移（displacement）、订单块、FVG，配合 killzone 时段与 premium/discount 定价（50% 回撤中分位）。

实体 vs 影线：实体收盘越位 = 真突破；影线刺穿收回 = 扫荡/假突破。

✓

Pin Bar 三要件：影线 ≥ 实体 2 倍、鼻子伸出结构、收盘收复。

✓

供需区看新鲜度：首次回踩最优，2–3 次显著测试后失效；离开必须爆发式。

✓

等扫荡再进场：不与等高点/等低点正面交锋，等止损被收割 + CHoCH 确认。

✓

OB 三要件：最后一根反向K + 引发 BOS + 强位移（≥3 根同向实体）。

✓

FVG 三K结构：K1 与 K3 影线间的空隙；回补是磁铁，实体穿越则极性反转。

✓

自上而下：HTF 定方向 → MTF 定位置 → LTF 定时机；逆大周期 = 负期望。

✓

R 优先：1:3 的盈亏比只需 25% 胜率保本——用 A+ 筛选换 R，而非用频率换胜率。

✓

止损即证伪：先定"什么价格证明我错了"，再由距离反推仓位。

✓

80% 法则：大部分突破失败、大部分时间震荡——做回调优于追突破。
