01 · 起源与核心哲学

像复合人一样思考

威科夫只用三样东西读市场：价格、成交量、以及它们所处的趋势位置。他的全部理论建立在一个思维实验上——把市场想象为由一位精明的"复合人"操控，研究图表时问自己："如果我是他，此刻我会怎么做？"

1873–1934 创始人

理查德·D·威科夫 Richard D. Wyckoff

15 岁入行跑单，25 岁拥有自己的经纪行，后创办《华尔街杂志》（发行量一度超 20 万份）。近距离观察利弗莫尔、基恩等大操盘手的实战手法，1931 年在纽约创办股市科学研究所，课程《股票市场科学与技术教程》成为传世教材。

思维模型 核心概念

复合人 Composite Man / Operator

把所有大资金拟人化为一位"操盘手"：低位悄悄吸筹 → 拉抬价格 → 高位派发给公众 → 压价退出。他的一切行动都为自身利益服务，且必然在图表上留下量价足迹。价格周期，就是他的资金曲线。

对手盘 博弈视角

他制造你的情绪

跌到抛售高潮让你恐惧交出筹码，涨到购买高潮让你贪婪高位接盘；Spring（弹簧）与 UTAD（派发后上冲）是他故意设置的陷阱——先扫掉你的止损，再启动真正的行情。

传承 · 比喻大师

Bob Evans

威科夫课程的执教者之一，贡献了小溪（Creek）与冰面（Ice）的比喻体系，以及 Spring（弹簧）这一术语。

传承 · 体系化

Hank Pruden

将结构图整理为 A–E 五阶段模型、系统化九项检验，著作《顶级交易三大技能》是现代威科夫教学的基石。

传承 · VSA

Tom Williams

曾任机构操盘手，把威科夫量价原理发展为 VSA（量价分化分析）：价差 + 收盘位置 + 成交量，置于背景下解读。

传承 · 当代

Weis / Coulling / Villahermosa

David Weis 的威斯波浪、Anna Coulling《量价分析》面向大众、Ruben Villahermosa 的现代畅销教材——方法在量化时代依然被专业交易员沿用。

为什么百年不衰
无论主力用人工还是算法执行，建仓 → 拉升 → 出货 → 压价的行为周期无法省略——大资金进出必然留下量价足迹。高频交易只是把吸筹与派发做得更快、更碎，底层供需逻辑从未改变。这是威科夫方法穿越一个世纪依然有效的根本原因。
02 · 市场周期

四阶段循环：主力的作战地图

市场永远在四个阶段间循环：吸筹 → 拉升 → 派发 → 下跌。横盘不是"没有行情"，而是主力活动最密集的战场；趋势只是横盘孕育的"果"。识别当前所处的阶段与位置，是一切量价分析的前提——同样的信号，位置不同，含义相反。

阶段①

吸筹 Accumulation

下跌末端的横盘区间。公众在恐慌中交出筹码，主力静默接货。区间即战场——"因"在此积累，吸筹的深度决定未来行情的高度。

阶段②

拉升 Markup

供给枯竭 + 需求主导，最小阻力方向向上。特征：高点低点持续抬升、上涨放量回调缩量。途中的再吸筹区间是趋势交易者的加仓点。

阶段③

派发 Distribution

上涨末端的横盘区间。公众狂热追高，主力借流动性出货。UTAD 牛市陷阱套牢最后一批买家，"因"在此转向空头。

阶段④

下跌 Markdown

需求枯竭 + 供给主导。反弹一次比一次弱——对多头而言每一次反弹都是逃命机会，对空头而言是做空入场点。

位置先于信号
分析任何图表的第一步：市场（和个股）处于四阶段循环的哪个位置？处于交易区间的哪个阶段？高位放量长阳可能是购买高潮（BC），低位放量长阳可能是强势信号（SOS）——脱离背景读信号，是量价分析最大的错误来源。
03 · 三大法则

一切判断的三条公理

三大法则是威科夫方法的"宪法"，所有结构、事件与检验都是它们的具体化：供需法则告诉你方向，因果法则告诉你空间，努力与结果法则告诉你转折。

Law 1 方向

供需法则 Supply & Demand

需求 > 供给 → 涨；供给 > 需求 → 跌；均衡 → 区间。判断依据不是新闻，而是量价行为本身：上涨放量 = 需求真实；上涨缩量 = 需求缺席（无需求）。最好的交易，发生在供需失衡最悬殊的位置——高潮与真空。

Law 2 空间

因果法则 Cause & Effect

横盘区间是"因"，随后的趋势是"果"。因的计量不是时间，而是点数图（P&F）横向计数：吸筹区间的计数深度决定上涨目标，派发区间决定下跌目标——"横有多长、竖有多高"的严谨版本。

Law 3 转折

努力与结果 Effort vs Result

成交量是努力，价格推进（价差）是结果。努力与结果背离 = 转折预警：巨量却推不动价格，说明有对手盘在吸收；缩量却能轻松推进，说明最小阻力方向已打开。

计数操作要点

Count Guide 实务

① 计数起点：以区间低点（或弹簧低点）所在行为计数线；② 保守优先：不同行计数结果不同，取最小值作为最小目标；③ 镜像对称：派发区间的计数向下投射；④ 目标性质：P&F 目标是"停、看、听"区域——减仓、收紧止损、观察反应，不是精确的反转坐标。

常见误读

时间 ≠ 因

"盘得越久涨得越高"是简化说法。因的度量是横向计数的列数，不是天数：一个窄而浅的区间哪怕横一年，计数可能还不如一个宽区间三个月。判断空间，永远回到计数本身。

检验 9 的由来
因果法则给出目标后，"预估盈利 ≥ 止损风险 × 3"（九项检验第九条）才有计算依据——盈亏比一票否决：目标不够远的形态，再完美也放弃。

停止行为 · 吸收

Stopping Action / Absorption

巨量下杀、极宽波幅，收盘却脱离最低点——努力巨大、向下结果有限：供给正被主力吸收，是下跌行情的"停止行为"。

上冲乏力 · 供给涌现

Effort to Rise, No Result

高位巨量长阳，价格却再无推进、随即回落——努力巨大、向上结果有限：上方供给正被抛出，出现在高位即购买高潮前兆。

无供应 · 看涨

No Supply

回调波幅窄、成交量极低——几乎没有人想卖。测试支撑时出现无供应，是供给已吸收的铁证（Test 的理想形态）；拉升途中的无供应回调 = 最佳加仓点。

无需求 · 看跌

No Demand

反弹波幅窄、成交量极低——几乎没有人想买。反弹测试阻力时出现无需求，证明买盘枯竭（UTAD 之后 Test 的理想形态）；下跌途中的无需求反弹 = 最佳做空点。

努力与结果的底层逻辑
成交量代表投入市场的"力量"，价差代表这股力量取得的"战果"。力量的消耗必然留下痕迹：向上使尽全力（巨量）却推不动（窄幅），力量被谁消耗了？——被看不见的卖方（吸收）；几乎不费力（缩量）却能推进（宽幅），说明对面无人抵抗（真空）。背离之处，即是真相所在。
04 · 吸筹结构

吸筹：A–E 五阶段全景图解

下跌之后的横盘区间，按证据链推进分为五个阶段：A 止跌 → B 构建因 → C 测试（弹簧）→ D 需求主导 → E 拉升。九大事件（PS、SC、AR、ST、Spring、Test、SOS、LPS、JAC）依次登场。注意：结构图是假设检验的框架，不是每张图都会凑齐所有事件。

A 止跌

阶段 A · 供给的最后狂欢

PS 初步支撑：下跌途中首次明显放量承接——波幅放大、跌速放缓、收盘脱离低点，专业资金进场的第一证据。SC 抛售高潮：恐慌总爆发，巨量 + 极宽波幅 + 长下影，收盘常回到区间中部——大量筹码从公众转移到专业买方（"停止行为"）。AR 自动反弹：卖压暂竭引发的技术性反弹（空头回补 + 抄底盘），其高点定义区间上沿。ST 二次测试：再次下探 SC 区域复核供给，理想形态是量能与波幅双缩、低点不低于 SC。

⚠ 若 ST 明显跌破 SC，预示新低或更漫长的盘整；PS–SC–AR–ST 四部曲越完整，吸筹定性越可靠。

B 构建因

阶段 B · 主力的战场

区间正式成形，多空反复拉锯：数次类 ST 测试、对上下边界的假突破、量能整体递减。主力利用双向对倒掩饰吸筹——上涨时卖出压制（避免暴露意图），下跌时悄悄回补。"因"的规模（P&F 横向计数）在此积累：横盘不是浪费时间，是在为未来的趋势积蓄燃料。

⚠ B 阶段方向不可预测——它是假设的检验期而非方向期，教科书式的抄底亏损大多发生在这里。

C 测试

阶段 C · 黄金坑的诞生

Spring 弹簧：价格跌破区间支撑（SC/ST 低点）后迅速收回。三重目的：①触发止损单、收割残余浮动供给 ②诱空，让最后的悲观者交出筹码 ③主力以更低价格补足仓位。确认链条：跌破 → 快速收回 → Test（低量回测弹簧低点）——极缩量的 Test 是供给已被吸收的铁证，也是对 Spring 真伪的裁决。

⚠ 跌得深不等于破位失败——收回速度与 Test 量能才是裁判；没有 Spring 的吸筹同样存在（结构 #2：以最后一次 ST 充当 C 阶段测试）。

D 右侧

阶段 D · 需求主导的证据链

Test 通过后：SOS 强势信号（放量、宽幅上攻）——通常正是 JAC 跃过小溪的一跳；随后回落形成 LPS 最后支撑点（缩量、窄幅、低点抬高）。SOS/LPS 可交替出现多轮，低点持续上移——需求全面接管的证据链。BUCE 回踩小溪沿：Evans 的比喻——跳出小溪后回头把脚弄湿，即突破后的缩量回抽，经典右侧入场点。

⚠ D 阶段的 LPS 回调必须缩量；放量回调 = 区间内仍有供给，警惕价格重返区间。

E 兑现

阶段 E · 拉升

价格彻底离开区间，最小阻力方向向上。拉升途中会形成更短、更浅的再吸筹交易区间——注意其阶段 A 常长得像派发（没有 SC、PS 不明显），是趋势的"加油站"而非终点。

回调至再吸筹区上沿 / 原区间顶部 = 趋势交易者的加仓点（支撑阻力互换原理）。

C 阶段放大

弹簧的三种深度变体

按跌破支撑后的深度分为三型（见下图）：①未及前低——最温和的震仓；②触及前低——标准弹簧；③深破前低——终端震仓（Terminal Shakeout），带"烟火"的猛烈洗盘，往往伴随更急促的收回与更凌厉的后续拉升。深度越深、收回越快，随后的行情往往越强——弹簧被压得越狠，弹得越高。

① 未及前低

Spring Type 1 · 浅震仓

跌破支撑但未触及 SC 低点即收回——供给压力最轻的确认。

② 触及前低

Spring Type 2 · 标准弹簧

精确回踩 SC 低点区域后收回——教科书式的弹簧形态。

③ 深破前低

Spring Type 3 · 终端震仓

远破 SC 低点的猛烈洗盘——吓出最顽固的持仓者，收回越快，后续动能越强。

小溪与冰面 · Evans 的比喻
长期下跌后，卖压如溪水般逐渐"退潮"，沿反弹高点连成的曲折阻力线就是小溪（Creek）。价格第一次跳过小溪（JAC）后常回踩溪沿"弄湿脚"（BUCE）再上行——那是趋势给人的第二次上车机会。镜像地，派发区间沿回调低点连成的支撑线是冰面（Ice）：价格跌破冰面后每次反抽都是逃命机会——掉进冰水里，别指望冰面再托住你。
05 · 派发结构

派发：吸筹的镜像

上涨之后的横盘区间，事件与吸筹一一对称：PSY–BC–AR–ST 对应 PS–SC–AR–ST，UTAD 对应 Spring，SOW–LPSY 对应 SOS–LPS。主力在此完成出货，把筹码交给狂热的公众。读懂派发，才能在"最后的狂欢"里全身而退。

A 止涨

阶段 A · 需求的最后狂欢

PSY 初步供应：涨势中首次出现明显供给——放量滞涨、上影拉长、涨幅收窄。BC 购买高潮：公众狂热追顶 + 主力借机出货，巨量、极宽波幅、收盘脱离最高点；利好满天飞往往正是此刻。AR 自动回调：买压暂竭后的技术性回落，低点定义区间下沿（冰线锚点）。ST 二次测试：反弹复核 BC 区域，理想形态量能波幅双缩、高点不创新高。

⚠ BC 的收盘位置是关键：巨量长上影收在中部以下 = 上方供给真实涌出。

B 构建因

阶段 B · 出货的伪装

区间震荡，主力掩护出货：下跌时买回托住价格（维持区间假象），上涨时分批派发。对上下边界的反复测试中，UT 上冲开始出现——冲上阻力后无力维持、回落区间内，即需求不足的早期证据。量能整体递减，反弹的量一次比一次弱。

⚠ B 阶段的反弹缩量（无需求）是派发定性的重要证据，而非"洗盘"。

C 测试

阶段 C · 牛市陷阱

UTAD 派发后上冲：价格冲上区间阻力、看似突破创新高，随后迅速跌回区间内——Spring 的镜像。三重目的：①测试残余需求是否已被榨干 ②在更好的价位完成最后出货 ③把最后一批追多者套在山顶。确认链条：冲高 → 失败跌回 → Test（反弹极缩量）——反弹无需求 = 买盘枯竭的裁决。

⚠ 没有 UTAD 的派发同样存在（结构 #2）；UTAD 不必创新高，冲破阻力再失败即算。

D 右侧

阶段 D · 供给主导的证据链

Test 确认无需求后：SOW 弱势信号——放量、宽幅下杀，跌破冰线；随后反弹形成 LPSY 最后供给点（缩量、窄幅、高点降低，反抽至冰线下方即告失败）。反弹一次比一次弱，低点持续下移——供给全面接管的证据链。LPSY 是多头最后的逃命点，也是空头的高胜率入场点。

⚠ LPSY 反弹必须缩量；放量反抽逼近冰线上方 = 区间内需求仍在，警惕重返区间。

E 兑现

阶段 E · 下跌

价格彻底离开区间，最小阻力方向向下。下跌途中形成更短更浅的再派发交易区间——每一次反弹至再派发区都是减仓 / 做空机会。公众在"便宜了"的幻觉中不断接飞刀，主力在反弹中清空最后的存货。

易混点

UT ≠ UTAD

UT（上冲）可出现在 B 阶段：试探性冲高评估需求，是噪音级证据；UTAD（派发后上冲）专指 C 阶段的结构性终极上冲——它之后市场必须走弱（Test 无需求 + SOW）才算确认。实战含义：见到 UT 不必立即做空（可能只是 B 阶段震荡），见到 UTAD 后的首次 LPSY 才是高胜率空点。

派发比吸筹更难读
顶部区间的情绪是狂热而非恐惧——好消息不断、专家一致看多、突破假象频出，做空者反复被打脸。威科夫的忠告：不要预测顶部，只交易证据链完整的 D 阶段（UTAD → 无需求 Test → SOW → LPSY）；在 C 阶段之前，永远假设趋势仍向上。

记忆口诀
吸筹四部曲"停、反、测、弹"（PS 止跌 → SC 高潮 → AR 反弹 → ST 测试），派发四部曲"停、回、测、冲"（PSY → BC → AR → ST/UT）；C 看陷阱（Spring / UTAD），D 看证据（SOS–LPS / SOW–LPSY），B 阶段只观察、不下注。
07 · 量价细节

阅读成交量的军规

价格告诉你"发生了什么"，成交量告诉你"为什么会发生"。量价组合的解读没有灰色地带——每一组行为都对应唯一的供需状态，前提是把它放进正确的背景（位置）里。

价格行为成交量名称解读
宽幅下杀，收在中部以上巨量抛售高潮 SC恐慌出清 + 主力吸收，趋势末端信号
巨量下杀后窄幅持稳急缩Test / 停止行为确认供给枯竭确认，下杀动能已被吸收
窄幅下跌极低无供应 No Supply没人想卖 → 看涨，最佳加仓信号
窄幅上涨极低无需求 No Demand没人想买 → 看跌，反弹乏力的铁证
宽幅上涨但无后续跟进巨量上冲乏力高位 = 供给涌现 / 对倒出货（BC 前兆）
宽幅上涨且持续跟进放量强势信号 SOS需求真实且主导，突破有效
回调至支撑 / 小溪沿递减LPS 特征回调中供给缺席，右侧入场窗口
拉升途中缩量上行低量供给真空最小阻力方向畅通，趋势健康

六条军规 · 一

量是努力，价差是结果

任何单一根 K 线都必须同时看两个维度。背离（巨量窄幅 / 缩量宽幅）本身就是信号，比单纯的方向信息更有价值。

六条军规 · 二

高潮量在转折，不在中段

巨量高潮（SC / BC）几乎只出现在趋势末端。趋势中段的量能应当有序递增——中段出现天量，警惕转折提前到来。

六条军规 · 三

测试必须缩量

ST、Test、LPS 的合法性全部建立在量能收缩上。不缩量的测试是警告：那不是测试，是还有对手盘在场。

六条军规 · 四

收盘位置 > 波幅

同样宽幅的 K 线，收在上 1/3 与收在下 1/3 是两个世界。收盘位置揭示多空谁赢得了这根 K 线的战争，是 VSA 的核心变量。

六条军规 · 五

背景决定含义

同样的巨量长阳：下跌末端 = 停止行为，高位区间 = 购买高潮，趋势中段 = 需求延续。先定位阶段，再解读信号。

六条军规 · 六

波段视角：波图

威科夫用波图（Wave Chart）把 3–5 根 K 线组成一个"操作波"，比较连续上涨波与下跌波的幅度、时长与量能——努力与结果在波段级别的应用，判断多空力量的整体消长。

VSA：威科夫量价原理的现代封装
Tom Williams（前机构操盘手）在《Master the Markets》中把威科夫的量价原理封装为 VSA（Volume Spread Analysis）三要素：价差（Spread）× 收盘位置（Close）× 成交量（Volume），置于市场背景下解读。核心信号包括 Stopping Volume（停止量）、No Demand / No Supply（无需求 / 无供应）、Upthrust（上冲）、Shakeout（震仓）、Effort to Rise / Fall（上攻 / 下杀努力）。Anna Coulling 的《量价分析》进一步将其系统化——它们与本文的九大事件一一对应，只是术语不同。
08 · 九项检验

扣动扳机前的九道检查

如果说三大法则是宪法，结构图是地图，九项检验就是入场前的发射程序：判断交易区间是否接近尾声、新趋势是否即将展开（最小阻力方向是否确立）。出处：Pruden《顶级交易三大技能》（2007）整理自威科夫课程原文。原则：满足的检验越多，胜率越高；但第 9 项拥有一票否决权。

最常被跳过 · 检验 7

相对强度：个股不是孤岛

威科夫课程原文：四分之三以上的个股与大盘同步。不把指数放在旁边对照，你无法知道一只"完美吸筹"是个股独立行为，还是 merely 跟随大盘的贝塔。真正的强势股 = 指数反弹时涨得更多、指数回调时跌得更少——这是机构资金聚集地的指纹。

一票否决 · 检验 9

3 : 1 盈亏比的算术

唯一带数字的检验，也是唯一能否决一个完美形态的检验：若 LPS 距离止损 3 元、而 P&F 目标距入场只剩 6 元——放弃。3:1 的盈亏比意味着 25% 胜率即可保本；用筛选换盈亏比，而不是用频率换胜率。

威科夫的原话
"在所有检验指向同一个方向之前，不要建仓。满足的检验越多，成功的概率越大。"——九项检验不是打分制，而是发射检查单：可以带着一两项未满足进场，但必须清楚知道自己在承担哪一项风险、为什么仍然值得。
09 · 五步法与实战战术

从研判到扣扳机的完整流程

威科夫的选股与入场五步法（Wyckoff's Approach）是一个自上而下的作战计划：先市场、再个股、再就绪度、最后择时——顺序不可颠倒。

1

判断大盘

市场处于四阶段循环的哪个位置？供需分析指向哪个方向？→ 决定做多、做空还是观望。逆大盘的交易从一开始就背负赔率。

2

选择同向个股

涨势中选强于大盘者（反弹更劲、回调更抗跌）；跌势中选弱于大盘者。拿不准就跳过——永远有下一只。

3

筛选"因"足够大

用因果法则：只做吸筹 / 派发区间 P&F 计数 ≥ 最低盈利目标的标的——因不够，果不来。

4

确认就绪度

九项检验：区间是否接近尾声？最小阻力方向是否确立？供给是否已被吸收？——不齐不下注。

5

借大盘择时

3/4 以上个股与大盘同步：等大盘转折信号（纸带阅读 / 三 K 净额法）出现再入场，设好初始止损并跟随移动。

计划 A · 激进：弹簧入场 Spring Entry

  • 入场：Spring 跌破支撑后快速收回的当日 / 次日，或低量 Test 确认时
  • 止损：Spring 最低点下方（结构证伪位，空间小）
  • 加仓：SOS + JAC 突破后，回踩 LPS / BUCE 加至全仓
  • 优势：止损距离最小，盈亏比最高
  • 代价：胜率换盈亏比——弹簧可能失败，需快切

计划 B · 稳健：LPS 入场 Right-Side Entry

  • 等待：SOS + JAC 确认区间目的已暴露，方向尘埃落定
  • 入场：缩量回踩小溪沿 / LPS 时
  • 止损：LPS 低点下方
  • 优势：胜率最高——右侧证据链完整，方向已确认
  • 代价：牺牲弹簧到 SOS 之间的一段利润，止损距离更大
做空镜像
计划 A'：UTAD 冲高失败跌回区间时做空，止损设于 UTAD 最高点上方；计划 B'：SOW 破冰线后，缩量反抽 LPSY 时做空，止损设于 LPSY 高点上方。目标同样由派发区间的 P&F 计数向下投射，盈亏比同样执行 3:1 一票否决。
退出 · 一

目标区：停、看、听

到达 P&F 计数目标≠必然反转：减仓、收紧止损、观察量价反应。出现对己方不利的结构信号（多单遇 BC / UT、空单遇 SC / Spring）才离场。

退出 · 二

结构证伪即离场

LPS 被跌破 = 吸筹假设证伪；LPSY 被升破 = 派发假设证伪。止损设在结构失效位，而不是资金承受位——位置由市场决定，仓位由止损反推。

退出 · 三

战役原则 Campaign

威科夫把一轮完整持仓称为"战役"：计划 → 试仓 → 顺势加仓金字塔 → 移动止损 → 目标区了结。铁律：绝不向亏损仓位加码摊低；认错要快，让利润奔跑。

10 · 误区与局限

威科夫也救不了错误的使用者

方法的主观性是特征也是陷阱。以下错误几乎出现在每一个初学者的第一笔亏损里——多数不是方法失效，而是方法被用错。

误区 · 一

横盘 ≠ 吸筹

横盘只是横盘。只有证据链到位（缩量测试、低点抬高、SOS）才能定性为吸筹。下跌中继的横盘（再派发）长得和吸筹一模一样——区别在量价细节，不在形状。

误区 · 二

模板 ≠ 承诺

结构图是假设检验框架：允许事件缺失（无 Spring 的吸筹 #2、无 UTAD 的派发 #2）。强行给每根 K 线贴标签、要求图表凑齐所有事件，是把地图当成了领土。

误区 · 三

个股 ≠ 孤岛

跳过检验 7（相对强度）= 闭眼交易：大盘下跌中的"完美吸筹"多数只是反弹中继。指数永远摆在个股旁边。

误区 · 四

B 阶段抄底摸顶

"因"未构建完成就下注 = 赌方向而非交易证据。B 阶段只做一件事：观察并计数，把弹药留给 C 和 D。

误区 · 五

目标 ≠ 精确点位

P&F 计数目标是"停、看、听"区域，不是反转坐标。到目标区就减仓收紧止损，不要等市场精确服从你的算术。

误区 · 六

信号 ≠ 仓位

盈亏比不达 3:1（检验 9），再完美的形态也放弃。威科夫交易的频率本来就低——等来的 A+ 结构，才是全部利润的来源。

方法的边界
威科夫本人承认：此法无法完全机械化，事件识别存在主观性与确认滞后（结构常常走完才完全确认）；算法与高频让现代市场的结构更快、更碎，日内噪音更重。但它分析的底层对象——大资金的进出与人群的情绪——从未改变。正确的定位：威科夫提供的是解读市场的框架与纪律，而非自动印钞机。
11 · 速查清单

一页带走全部要点

✓

先看大盘再看个股：四分之三个股随大盘——逆大盘的形态天然降级。

✓

像复合人一样思考：每根 K 线背后问"主力此刻想让我做什么"。

✓

三法定纲：供需定方向，因果定空间，努力与结果定转折。

✓

位置先于信号：同样的量价组合，高位与低位含义相反。

✓

PS–SC–AR–ST 四部曲= 下跌刹车；SC 收盘位置是吸收与否的裁决。

✓

Spring 是机会，Test 是裁决：弹簧之后没有低量测试，就不是弹簧。

✓

买在 LPS，不追在 SOS：突破后的缩量回抽才是右侧入场点（BUCE）。

✓

小溪之上不言顶，冰线之下不言底：BUCE 是二次上车，LPSY 是最后逃命。

✓

测试必须缩量：不缩量的测试 = 对手盘还在场 = 警告。

✓

计数而非时间：P&F 横向计数才是"因"，天数不是。

✓

检验 7 别跳过：相对强度是机构资金的指纹。

✓

3:1 一票否决：盈亏比不达标，形态再完美也放弃。
